| 提案用途 | 唯一执行/提交者 | 输出与权限 |

## 观察、授权与证据

提案只引用依据观察中的有效检测句柄；世界 ID、句柄到实体的映射、隐藏接触及未观察真值留在世界侧。能力登记与调用方冻结的会话/上下文决定权限；confidence、学生自填 quantity、学生自填 schema 都不能成为权限来源。

quantity 只取可信上下文按观察通道与能力语义导出的有限允许量；字段名别名检查递归覆盖 params 与登记 schema 的受支持分支。未知量、未知开放 schema 分支及不可规范化输入拒绝。字段名检查不构成任意隐写均已消除的证明，值语义和真实消费者的隔离仍需后续实现验证。

TTL 继续按原裁决的闭区间 `[basis.t_ticks, basis.t_ticks + ttl_ticks]`，不因其他契约的控制租约区间而改变。证据摘要继续采用既有 JCS 规则；原始文件 SHA 与 JCS 内容摘要分栏。异常退出、其他规则顺带捕获不能替代专属反例和关闭匹配规则后的真实漏检证明。
