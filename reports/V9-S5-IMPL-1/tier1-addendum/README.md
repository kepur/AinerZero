# 一级补充（2026-11-12）：R1 标签加物体占比 `obj`

**原因：** 设计 r1 §4 要求 R1 的对数深度 RMSE 按「物体块、地面块」分开报，但 P229 的 `labels.r1` 只给了 `logd` 和 `sky`，缺按块的物体信息。一级在第一次物化启动后发现了这个缺口，于是停下物化，删掉部分输出（都是刚生成、可以重新生成的中间数据），补上这一项再重新物化。

**改动：**
- `labels.r1` 多返回 `obj [16,14,14] float32`：每个 16×16 块里编号 ≥ 0（墙、柱子、圆盘）的像素占比。地面占比 = 1 − sky − obj。
- `materialize.py` 写入 `r1_obj`。

**测试：**
- `test_r1_object_share_geometry`（新）：面对 2 m 外的墙，地平线上方一行块 obj=1，最下一行 obj=0，并与编号图逐块核对。
- 预渲染一致性测试和物化端到端测试都加了 `obj`。

**源码坏对照（隔离副本）：** 3 处改动全部拦住，见 `mutations-obj-output.txt`。
- O1 只算编号 > 0（漏掉墙）；
- O2 物化时不写 `r1_obj`；
- O3 物化时把 `sky` 当成 `obj` 写入。
