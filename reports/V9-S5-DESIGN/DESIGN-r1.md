## 0. 问题

S5 在架构里的一行：学生端编码器的蒸馏与微调、多教师合一、教师对齐作加速项、RLT 开关、E6 真实视频泛化。门：对象 ID 不泄露；遮挡、3D 关系分别报告；外部预训练如实标注；未知尺度显式标记。

P224 盘点给出三条约束：
- 教师特征缓存一份都没有；
- 没有许可清楚、能直接进训练的像素数据；
- 世界脑主干（S1 一期、E1）不吃像素。

所以第一阶段全部在**自己渲染、许可干净**的画面上做，只回答下面三个问题。E6 要下载真实视频，不在本阶段，留给用户另批。

- **Q1 教师价值（E4 的本机版）：** 先用无标签画面把冻结教师蒸馏进一个小 MLX 学生，再用少量标签训练读出头。对照是同一个学生、同样的标签量、不蒸馏、直接监督训练。蒸馏的学生能不能用更少的标签达到同样的读出精度？算成本时，渲染和教师抽取的时间都要算进去。
- **Q2 教师对齐当加速项（式 11）：** 在直接监督训练上加 `η L_align`，达到同一读出精度需要的步数和墙钟是否明显更少？
- **Q3 RLT（式 10）：** 去掉停帧重复块之后，token 保留率、每步墙钟、读出精度各变多少？

外观换域（换颜色、光照、纹理）是 E6 的廉价替身，只单独报告，不当真实视频泛化。

## 1. 摸底（`tier1-explore/`，未登记，不作结论）

所有摸底都在未登记的 `s5x-explore` 命名空间上做：4 个世界，每个世界 6 个圆盘、64 步，渲染 224×224。

- 样图见 `round-a-frames-textured.png`。

**第 A 轮：教师在这类画面上有没有信号**（`explore_s5a.py`、`round-a/result.json`）：
- DA2 Small（Core ML，CPU_AND_NE，518×392，F16）：
  - 输出与真值深度的 Spearman，非天空像素中位 −0.988，只看物体像素（墙、柱、圆盘）中位 −0.981。负号说明输出是逆深度式（越近越大）。
  - 对照「只按行号猜」：非天空 0.69（地面深度只取决于行号），物体像素 0.01。所以 DA2 读的是画面内容，不是画面位置。

- V-JEPA 2.1 ViT-L：
  - 224 分辨率、16 帧一段，靠 RoPE 插值，不用裁剪；

  | 截断逆深度 R² | 0.94 | 0.67 | 0.66 |

## 2. 数据

**世界：** S4 圆盘世界（`src/ainerzero/v9/experiments/s4/world.py`）的场地、柱子、圆盘与智能体轨迹，每个世界 6 个圆盘，取前 256 步，切成 16 段、每段 16 帧。

**画面：**
- 224×224，水平视场 90°，相机高 0.5，带纹理。
- 渲染器移进 `src/ainerzero/v9/experiments/s5/render.py`，由二级照摸底版实现，并配契约测试（§7）。
- DA2 的帧另外渲染成 518×392，焦距按画面高度与学生帧取同一比例（f = 196 像素）。这样 DA2 帧中间那块 392×392，正好对应学生帧的视野，DA2 两侧还多看到一些上下文。蒸馏目标从中间那块取，缩到 56×56。
- 摸底版 `render()` 按 90° 水平视场算焦距，直接传 518×392 会得到 f = 259，中间块只有 74° 视场，边缘错位 8.8 个 token（P226 复核 B 的 P0）。正式版 `render()` 必须有显式焦距参数 `f`（默认仍按 90° 水平视场），DA2 帧一律传 `f=196`。

**学生输入：** 只有 RGB 帧。智能体位姿、对象编号、深度真值都不进学生输入。

**标签（只给读出头与评测）：**
- **R1 深度：** 每个 16×16 块的对数深度（深度截到 ≥ 0.5，只取非天空像素），外加天空占比。
- **R2 圆盘占据图：** 取每段最后一帧，把画面里看得见的圆盘放到自我中心网格上：方位 12 格覆盖 90° 视场，距离 7 格按对数从 0.5 到 7.0。每格是 0/1 占据：同一格里有几个圆盘都记 1，不记计数、不记编号。完全被挡住的圆盘不算。
- **R3 下一时刻占据图：** 同一网格，取 8 帧之后那一帧，读时序。
- **遮挡分组：** 每个圆盘按「看得见的像素 ÷ 拿掉柱子和别的圆盘后应有的像素」分组，< 0.5 记为部分遮挡，其余记为完整可见。
- **距离分组：** < 2 m、2–4 m、> 4 m。
- **前后次序（3D 关系，只评测用）：** 对每段最后一帧里看得见的「圆盘对圆盘」「圆盘对柱子」两两组合，真值是谁更近。预测取 R1 读出头在各自中心块上的对数深度。编号只在评测时用来配对，不进学生，也不进读出头。

## 3. 学生与各臂

**学生：** 时空 ViT，块 16、管长 2、224²、16 帧，宽 192、深 6、3 头，约 3.5 M 参数，位置编码可学。选这个规模的原因：
- 第 B 轮里它每秒 54 段，预算放得下；
- World Mode 要常驻它，越小越好。

宽 256 只在复核认为需要时，作为规模敏感性在 dev 上看一次。

**读出头：**
- R1：每个 token 接一层线性头，输出 2 个 token 的深度（管长 2），外加天空占比。
- R2、R3：注意力池化（1 个可学查询）接两层 MLP，输出 12×7 个 logit，用 BCE。

**训练方式：** 主比较是「冻结学生 + 训读出头」，这是表示质量的常规量法；另报「全量微调」。A0 没有预训练，只能端到端训练。

| 臂 | 用无标签池做的事 | 用有标签集做的事 |
|---|---|---|
| A0 无教师 | 不用 | 学生和读出头一起端到端训练 |
| A1 深度教师 | 蒸馏 DA2：DA2 只跑每个管长的第二帧，取中间块缩到 56×56 作目标；每个 token 用线性头出 4×4 逆深度，每帧用尺度与平移不变损失（MiDaS 式） | 冻结学生，训读出头；另报全量微调 |
| A2 V-JEPA 教师 | 蒸馏 V-JEPA：学生 token 经线性投影（192→1024），与同位置的 V-JEPA token 做余弦损失。两边的块、管长、分辨率一样，一一对应 | 同上 |
| A3 双教师 | 一个学生、两个教师头，损失 = L_DA2 + L_VJEPA，权重 1:1，冻结 | 同上 |
| C-sh 打乱教师 | 选出 A* 之后再生成，教师与 A* 相同：A*=A1 打乱 DA2 目标，A*=A2 打乱 V-JEPA 目标，A*=A3 两个都打乱。每段的目标换成另一段的（固定置换，置换种子冻结），算量、超参与 A* 完全相同 | 同上 |
| A4 对齐加速 | 不用 | A0 加 `η L_align`（式 11）。学生第 3 层后的 token 经投影头对齐 V-JEPA 同位置 token，`sg` 停梯度 |
| R | 与 A* 相同，但开 RLT（τ=0.02，按管长 2 比较，式 10 原样：比较相邻管长，不是上一个保留的 token）。被并掉的块不进注意力，留下的 token 加游程长度嵌入 | 冻结学生，训读出头；只在 L=512 上跑 |
| A0-R | 不用 | A0 开 RLT，只在 L=512 上跑 |

**标签量 L（段数）：** 64、512、2048，每档都跑 A0–A3 和 C-sh。lab 的子集按世界抽：L=64 取 4 个世界，L=512 取 32 个，L=2048 取全部 128 个。子集嵌套，抽法的种子冻结。

**选臂：** 在 dev 上，按 L=64 的 R2 AP（两个蒸馏种子 × 三个读出种子的平均）从 A1、A2、A3 里选一个，记作 A*，写进预登记后冻结。final 上的门只检验 A*，避免在 final 上挑最大值。C-sh 和 R 都在选出 A* 之后才训练。

**尺度：** DA2 只给相对深度，尺度未知。A1、A3 的 DA2 蒸馏只用尺度与平移不变损失。从 DA2 来的东西，一律不报米制误差，并显式标「尺度未知」。R1 的对数深度是真值标签，可以报米制。

**外部预训练声明：** 能力报告和 `describe()` 写明三项：
- V-JEPA 2.1 ViT-L：MIT，许可正文在 `envs/teachers/src/vjepa2-mlx/LICENSE`；
- Depth Anything V2 Small Core ML：模型卡写 apache-2.0，本机没有许可正文，如实写明；
- 学生只经蒸馏间接用到这两个教师，不带教师权重。

## 4. 指标、门与统计

**指标（final，三个种子取平均）：**
- R2、R3：AP，所有段、所有格子微平均。另报三项：
  - 按遮挡分组的召回（用 dev 上选的阈值）；
  - 按距离分组的 AP；
  - 换域两档各自的 AP。
- R1：非天空块对数深度的 RMSE，另按物体块与地面块分开报。
- 3D 关系：前后次序准确率，分「圆盘对圆盘」「圆盘对柱子」，再按遮挡分组报。
- 多教师合一：A3 − max(A1, A2) 的 R2 AP 与 R1 RMSE 差值，带 95% 区间。只是描述：max 是挑出来的，对 A3 偏严。
- RLT：token 保留率；还原误差 `‖clip − restoration‖∞` 的中位数与 95% 分位（式 10 比较相邻管长，慢变化会累积，P226 复核 B 的 P2）。
- 成本：
  - 每个臂达到「A0 在 L=2048 的 R2 AP」所需总墙钟，含渲染与教师抽取；
  - 达不到就报「未达到」与最好成绩。
  - 电量：本机没有免 sudo 的功率读数，记「未测」，不估算。

**统计：**
- 以 final 的世界为单位做配对自助法，2000 次重抽；同一世界的 16 段一起抽。
- 种子先平均，再重抽世界。所以区间说的是「这几个种子平均后的模型」在世界分布上的不确定性，不包括换一组种子的波动。种子间的标准差另列，作描述。

| 门 | 判据 | 回答 |
|---|---|---|
| GT1 低标签教师价值 | L=64：A*（冻结 + 头）的 R2 AP − A0 ≥ 0.05，且 98.3% 区间下界 > 0 | Q1 |
| GT2 不是多算出来的 | L=64：A* − C-sh ≥ 0.03，且 98.3% 区间下界 > 0 | Q1 的对照 |
| GT3 深度 | L=64：A* 的 R1 RMSE − A0 的 98.3% 区间上界 ≤ 0.05 × A0 的 RMSE（非劣，边际 5%） | Q1 |
| GA 对齐加速 | L=512，在 final 上量。达标线 = 0.95 × A0 三个种子末次检查点 R2 AP 的中位数。每个种子取第一次达标的检查点步数，没达标记为预算上限步数（删失）。A4 三个种子步数中位 ≤ 0.7 × A0 的步数中位 | Q2 |
| GR RLT | L=512：A*-R 的 token 保留率 ≤ 0.8，蒸馏每步墙钟降 ≥ 15%，R2 AP 下降的 95% 区间上界 ≤ 0.03 | Q3 |

- GT1–GT3 是一族，按 Bonferroni m=3 取区间（每个 98.3%）。

- L=512、2048 两档的教师价值、全量微调、R3、换域、遮挡与距离分组都只报告，不设门。

**契约（实现验收时由测试把守，不是指标）：**

## 9. 风险

- **画面太简单，A0 在低标签档也学得很好，教师价值显不出来。** L=64 只有 64 段（1024 帧），A0 很可能过拟合，这正是 GT1 要量的。如果 A0 在 L=64 已接近 L=2048，就如实报「本世界里教师价值不可测」，不改门。

- **V-JEPA 特征缓存（约 21 GB）读写成为瓶颈。** 探针运行要量数据读取占每步的比例。
- **摸底时批量 16 比批量 8 慢，原因未查。** 正式运行固定批量 8；探针里复测。
- **RLT 按管长 2 比较时，首个管长的块总是保留。** 一段只有 8 个管长，保留率下限是 1/8，GR 的 0.8 门槛已考虑这一点。P226 复核 B 用静止画面实测是 0.125。
- **RLT 比较相邻管长，慢变化会累积。** 被并掉的块可能和真实画面差到 τ 的好几倍（P226 构造的渐变序列差到 6.75τ）。式 10 不改，但要报还原误差分布。如果误差大，就在报告里说明，作为后续「锚点式比较」的依据。
- **GR 很可能通过**（P225 复核 A 的判断）。纯背景块占 60%，τ=0.02 保留率 0.74。它回答的是「这个世界里 RLT 省多少」，不能外推到真实动画。

## 实现阶段补记（2026-11-12，一级决定，冻结前生效）

以下几处设计稿 r1 没写清楚，是实现时暴露出来的，由一级定下口径：

1. **R1 的物体块与地面块：** 标签加 `r1_obj`，即每块里编号 ≥ 0（墙、柱子、圆盘）的像素占比。object 块取 obj ≥ 0.5，floor 块取 1 − sky − obj ≥ 0.5（提交 233ca72）。
2. **网格 AP 的距离分组：** §4 的「< 2、2–4、> 4 m」是圆盘级分组。网格级 AP 只能按距离格的边界近似：near 是第 0–3 格（< 2.26 m），mid 是第 4–5 格（2.26–4.80 m），far 是第 6 格（> 4.80 m）。圆盘级召回仍按 < 2、2–4、> 4 m 分组（`metrics.py`，5d1c5d0）。
3. **RLT 下 R1 读出的取法：**
   - 被并掉的位置，学生输出的是零向量。R1 读出不能直接用零向量。
   - 规则：被并掉的位置，取同一空间位置上、它所在游程起点（最近一个保留的管长）那个 token 的输出，作为 R1Head 的输入。这就是 RLT 里「这个 token 代表整段游程」的意思。
   - 这条规则适用于 A0-R 的训练损失、冻结学生的读出头训练和预测。
   - GridHead 照旧用 keep 掩码做注意力池化。
   - R 臂的 DA2 蒸馏照旧把被并掉的 4×4 区域从 SSI 的 valid 里去掉。
4. **A4 对齐特征的取法：** 第 `align_layer` 层的特征必须取自本步同一次前向的缓存，不许为取特征再跑一遍学生。两种写法数学上等价，但再跑一遍会让 A4 每步的计算量翻倍，与 §6 的预算不符。
5. **R2/R3 读出头改为「逐 token 打分 + 按位置线性映射」（FlatHead）。** 证据见 `tier1-explore/` 第 D–K 轮，全部只用 lab：训练 lab 世界 0–31，验证 96–127，不碰 dev。
   - **现象：** probe 里，A0 用满 2048 段训练后，dev 上 R2 AP 只有 0.040。随机是 0.014，只用各格子正例率当分数是 0.023。
   - **标签可学：** 只用最后一帧的 28×28 蓝色占比做岭回归，验证 AP 就有 0.43（第 E 轮）。
   - **原头学不起来：**
     - 从零端到端训练，换逐格查询头、降学习率、给正例加权，R2 都约 0.03（第 D、F 轮）；
     - 冻结的随机学生与 probe 蒸馏学生配原 GridHead，也都约 0.03（第 G 轮）；
     - 原 GridHead 直接读 V-JEPA 特征，连训练集都只有 0.045，损失停在先验熵附近（第 H 轮）；
     - 按相机几何汇总的头也不行：训练集 0.025，加位置 one-hot 后验证集 0.048（第 I、J 轮）。
   - **新头有效：** 每个 token 线性投到 k 个分数，展平后一层按位置的线性映射到 84 格。直接读 V-JEPA 特征，验证 AP 在 k=1 时 0.125，k=4 时 0.200（第 K 轮）。
   - **规则：**
     - R2、R3 都用 `FlatHead(d, k=4)`，只读最后一个管长的 14×14 个 token；
     - 开 RLT 时先 `restore_runs` 再送入，不再用注意力掩码；
     - 损失仍是 BCE，不加正例权重。第 F 轮里，加权和降学习率对原头都没用，不作为改动依据。
   - 原 `GridHead` 保留在代码里，但不再用于任何臂。
   - 读出头是所有臂共用的测量工具，在冻结前更换，对各臂公平。dev 尚未用于任何选择。
6. **预算（用户 2026-11-12 批准，锁内总上限 22 h）。** 按 probe-20261112c 实测重写 §6，各段上限如下：
   - **冻结前 12 h：** 已用约 3.8 h，包括教师抽取 0.9 h、probe-b 1.1 h、probe-c 0.5 h、读出头摸底 D–K 约 1.3 h。剩余 dev-tune 上限 3 h、dev-distill 上限 8 h。
