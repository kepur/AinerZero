## 2. 逐项结论 1：是否守住 r5 冻结边界

**结论：基本守住，但有 2 处边界缺口（M8、M9）与 1 处措辞过强。**

### 2.1 §8.6 学习侧信息边界（守住）

ADR D1 写明输入为「自身信念、允许观察、学生已执行动作，以及登记配置（D_permit、阈值登记）」，并逐条排除 Event/v1、世界 ID、对象真值 ID、sim_truth、生成器偏差标签、评测通道。这与 `ARCHITECTURE_V9.md:357` 的三类信号一致，也与 `src/ainerzero/v9/interfaces/scheduler.py` 的模块契约（只接受三类信号、拒绝 Event/v1 与世界侧脏集合）一致。

ADR 还要求「在**实际加载路径**上测试」并通过「同观察、异未来」反例——这正是 §8.6 最后一条的原文要求（`ARCHITECTURE_V9.md:363`）。这一点写对了，且比 DESIGN_CORE 更严。

**但 M8**：`D_permit` 是「边界教师」登记的配置。在「同观察、异未来」的两个世界里，`D_permit` 是**同一个常量**，因此该反例**在结构上测不到** `D_permit` 携带实验者知识的情况。举例：若登记 `D_permit` 时因为「我们知道评测世界的隐藏机制在区域 X」而把 X 划出可操作范围，则学习侧拿到的是一份关于隐藏机制位置的间接情报，而两个对照世界的观察与 `D_permit` 都相同，反例照样通过。这不是理论洁癖：ADR D5 把「允许泛化包络」也放进 `D_permit`，包络本身就是从数据/先验推出来的量。

要求：补一条 `D_permit` 来源审计——(a) 必须在实验登记**之前**冻结并记录 provenance（谁、依据什么、用什么数据）；(b) 明确禁止 `D_permit` 编码「某区域没有机制」这类否定性世界知识；(c) 在评测侧做一次「`D_permit` 去掉后重跑」的敏感性对照，报告路由分布变化。

### 2.2 FAST/MID/SLOW 与「教师与 LLM 不能写 SLOW」（守住，且现状证据成立）

- ADR D5 与 §4「明确不改」都写了教师三职责永不直写 SLOW、只进先验或 MID；§1 表（`ARCHITECTURE_V9.md:46`）的「教师与 LLM 永远不能直接写 SLOW」未被改写。
- 现状证据我独立核对过：`src/ainerzero/v9/interfaces/validation.py:268-300` 的 `PRODUCER_REGISTRY` 里 `"student": "self"`，黑名单只有 `{"teacher","llm","assistant","human_unreviewed"}`，**`self` 不在其中**，所以 `producer="student"` 确实能通过 `validate_producer`。ADR §1 表第 2 行的诊断成立，不是夸大。

### 2.3 ADR-0013 世界脑旁路（守住）

ADR §0 与 §4 两处都写了「不改 ADR-0013 角色优先主线：世界脑仍是旁路，不是出片前置，也不是 LLM 导演」，并明确 SLOW 机制库属于 AinerZero 学习侧、不混进 AWZ 世界侧登记。这与 `ARCHITECTURE_BASELINE.md:5-7` 的入口一致。

### 3.2 M1（必修，事实错误）：OSVerify 的「方向相反」不成立

ADR §3 末句：「OSVerify 控制的是『误拒有效解』（FNR）；本门控制的是**错误接受**——方向相反，不能照搬其指标。」`REPORT.md:61` 同口径。

一手来源（2610.18089 全文，本人抓取）原文：

> "We adopt the one-sided verification objective that **maximizes the rejection rate of invalid solutions (TNR)** under a constraint on the false-rejection rate of valid ones (FNR)"
> "maximize TNR subject to a low FNR constraint … This objective requires a verifier to reject as many invalid candidates as possible while limiting the fraction of valid solutions rejected."

也就是说：**TNR（拒绝无效解）是目标，FNR 是约束**。而「拒绝无效解」与本门要控制的「错误接受」是**同一方向**（TNR = 1 − 无效解中的错误接受率）。所以「方向相反」是错的。

这个错误不是无关紧要的：ADR 用它来论证「误拒只报告、不作门」。论证要成立，理由必须换成**代价不对称**，而不是方向相反：
- OSVerify 的误拒会永久丢掉一个稀有有效解（不可恢复），所以必须给 FNR 一个硬约束；
- 本门的误拒只是「晚一点晋升」，候选仍在 MID、证据账本只追加、可重测（可恢复），所以不设误拒门是**有理由的**，但理由是可恢复性，不是方向。

另外必须写清：OSVerify 报的 46% / 57%（以及图 1 的 52% / 34%、训练后 83% / 41%）全部是**在固定经验 FNR 约束（5%）下的工作点**。本门没有 FNR 约束，因此这些数字**在定义上不可移植**——这才是「不能照搬指标」的正确说法。

### 3.3 M2（必修，前提缺失）：e-LOND 的适用条件与已知失效

ADR D3-3 只写了 e-LOND 的公式，没写它成立所需的条件。一手核对 EGR 定理 2 的三个前提：

> "Assume (i) c_t is fixed before candidate-t decision evidence is opened, (ii) **Assumption 1 holds for every true component null**, and (iii) **allocation and stopping are predictable**. Then E_pers is conditionally valid under every true persistent null … Feeding these e-values to e-LOND yields online persistent-target FDR control at level α under the dependence conditions of Xu and Ramdas (2024)."

ADR 只覆盖了 (i)（「挑战者与 test_id 在看到决策证据前冻结」）。(ii) 与 (iii) 缺失，其中 (ii) 是要命的那条：EGR 的 Assumption 1 是**联合历史条件均值**条件，原文明确警告

> "Fresh independent draws satisfy it directly; with dependence, the valid unit may instead be a block or cluster. **A marginal mean condition for correlated raw rows is not sufficient.**"

本项目的「世界」内部有多回合、多步轨迹，同一世界的样本强相关。若按回合/步当独立单元喂 e-process，条件 (ii) 不成立，FDR 保证失效。**必须**写明：证据单元是世界级 block/cluster，不是原始行。

还有一条 ADR 完全没提、但直接决定这个设计能不能用：EGR 自己的基准里

> "development-only e-LOND remains valid for the development hypothesis yet attains **persistent FDR 0.621**"

即：**e-LOND 单独用在错的目标上会得到 0.621 的 FDR**，EGR 的贡献恰恰是上游的候选 e-value 构造与证据路由。ADR 现在把 e-LOND 当作「整条晋升序列的控制器」引用，却把 EGR 只当作「e-process 合成的出处」，读者会以为 e-LOND 是充分装置。必须补一句：**只有喂 E_pers（all-environment 目标）且目标被显式声明为「在每一族都优于现任」时，FDR 才被控制；喂 dev-only 的 e-value 会重演 0.621。**

### 3.4 M3（必修，不自洽）：没有统一错误预算

D3 现在同时用了四种误差装置，彼此关系没写：

1. D3-1 配对 bootstrap 的 **95% 单侧上界**（固定 0.05，硬编码）；
2. D3-3 单次作业的 **α/N** Bonferroni；
3. D3-3 序列的 **e-LOND α_t = α·γ_t·(R_{t−1}+1)**；
4. D3-8 的 **FactTest 次序统计量标定**（一手核对：OSVerify 附录 B.4 用 valid solutions 为 null 类、δ = 0.10、n = 100 校准点）。

问题：(a) 1 与 3 叠用会双重计费——bootstrap 的 0.05 若不再由 α_t 决定，序列控制就失效；若由 α_t 决定，则「95%」这个常数必须删掉。(b) 4 的 δ = 0.10 是**有限样本违反概率**，与 bootstrap 的分位点、与 e-LOND 的 α 是三种不同的误差语义，不能并列而不说明。(c) 「T 上只测一次」不准确：同一个 T 上至少跑了优越性、式 6 保持、逐例不回归三类检验，「只测一次」实际含义是「只测一个候选」。

要求：给一张错误预算表（每族 α、序列 α、标定 δ 与 n、bootstrap 分位如何由 α_t 导出、N 的定义与登记位置），并把「只测一次」改成「只测一个候选，三类检验共用同一 α_t」。

### 3.5 M4（必修，会让门误判）：双侧 χ² 的下尾

D1 第 4 条用**双侧** 1−α_s 区间判 `SUFFICIENT`，动作是「直接求解、缓存」。上尾（NIS 过大）确实意味着模型不足，逻辑对。但**下尾**（NIS 显著偏小）意味着 S_k 系统性偏大，即滤波器**过度保守**——此时模型未必错，但**不确定性是错的**。把这种情况也判成 `SUFFICIENT` 并缓存，等于把一个失准的协方差写进 SLOW 并被后续规划当作可信度使用，这与 D3-4 的「D_valid 依赖标定残差分位数」直接冲突（分位数会被过大的 S 污染）。

要求：拆出第 4 条的下尾为独立路由（如 `COVARIANCE_INCONSISTENT`），动作是「重标定 S 或 Q，不学习、不缓存、不进入 D_valid 标定」，并把它计入 MSG 混淆矩阵的一类。

### 3.6 S1（建议）：灵敏度口径是单步还是传播

D2-7 与 D6-⑥ 都写「与 **∂F_prior/∂φ** 正交」，即**单步**灵敏度。而 MOS 原文的约束是「orthogonal to the forward model **sensitives**」，在 ODE 语境下是**整条轨迹的输出灵敏度**（由灵敏度方程与 ODE 联立求解得到）。单步正交不足以阻止 r_θ 在多步 horizon 上吸收 φ 的误差——因为 φ 误差沿轨迹被放大后再由残差补偿。建议明确写成「对 k 步传播后的灵敏度矩阵 S_k^φ = ∂s_{t+k}/∂φ 正交」，或在报告里说明只用单步正交时的残余混淆，并把它作为 D2-7 的一条已知限制。

### 3.7 S2（建议）：式 7 与 EIG 不是同一个量

r5 式 7 是 `a* = argmax I(S; O_next | a)`，其中 S 是**状态**（belief）；D4 的 EIG 是 `½ log det(I + S⁻¹JΣ_φJᵀ)`，是**参数 φ** 的信息增益。两者不是同一个量。ADR 把 D4 挂在「式 7（信息增益）」下，容易被读成重定义式 7。建议一句话区分：D4 用的是式 7 的**形式**（同一个 argmax 结构），目标从状态换成参数，**不修改式 7**。

### 3.8 S3（建议）：FPCA 基与标定集必须分开

D3-4 允许「曲线残差先 FPCA 降维再在系数空间做 split conformal」。若 FPCA 基在 D∪C 上估计、标定分位数又在同一 C 上取，则基与标定不独立，共形覆盖的名义保证失效。建议写明：基在 D 上估计，分位数只在 C 上取；或基与分位数都用 split（一半估基、一半标定）。

### 4.5 M10（必修）：D6 的「假说」是潜在的新门

### 6.1 EMPIRIC（2609.35047）

**已核实的 ADR 论断**（逐字命中）：
- 「基线有三个」——摘要 "solves more tasks with fewer environment interactions than **all three baselines**"；正文 "We compare EMPIRIC with three baselines (1–3), an oracle-dynamics reference (4), and two ablations (5–6)"。**成立**。（附注：REPORT 记的「16/14/16」这三个数字的确切含义我**没有核实**，不作为本报告的判据；本卡只确认「基线个数 = 3」。）
- 「广义后验 λ = max(1, E_min/N)」——正文逐字："We set $\lambda=\max(1,E_{\min}/N)$, where $E_{\min}$ is the smallest loss over the fit and $N$ counts its error terms; this is the maximum-likelihood variance of the standardized errors if they were independent and Gaussian, bounded below by the nominal scale." ADR 说「（启发式，无理论保证）」——原文确实只给了「若独立高斯则为 MLE 方差」的条件解释，没有保证，ADR 的标注**准确**。
- 「RMS 标准化误差 > 2 的段剔除并上报」——正文逐字："A segment is excluded when even its own best replay, over a grid of parameter settings, leaves a root-mean-square standardized error above 2; it is reported to the agent as evidence of a missing mechanism"。**准确**。
- 「残差只读净化后的观测与动作，不碰引擎内部」——正文："The class method `update_model_state` receives **sanitized** observations, the preceding action, and a parameter vector … It has **no engine access or privileged state**." **准确**。
- 「全部代理用 Claude Opus 5」——正文："All seven agents use Claude Opus 5 at high effort"。**准确**。

**需精确的 1 处（S4）**：EMPIRIC 的残差**不是**一个数值修正项，而是**写进引擎的代码**（"a physics engine extended with code for the missing mechanisms. The learned programs can introduce new forces, constraints, and hidden state"）。所以「不碰引擎内部」只能读作「不**读**引擎的特权状态」，不能读作「不**改**引擎的动力学」。r5 式 8 的 r_θ 同样会改变预测的下一个状态。建议 ADR 改成「残差只读净化后的观测与动作，不读引擎特权状态；但它对预测状态的修正是允许的，这正是式 8 的 ⊕」。
