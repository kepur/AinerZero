## 结论：打回（2 项必修）

r0 的 4 项必修都处理了，方向对。动力学进了滤波器以后，懂碰撞在有碰撞事件上值 +0.23；不懂交互的模型，不管只调噪声还是用常速度，都过不了 C 门。摸底能逐项复现，只碰 `s4x-explore`。

剩下两个问题都出在 C 上：
1. C 被过程噪声的大小左右，而学习模型和手写模型的噪声不可比；
2. C 很快饱和：只懂一半碰撞的模型就能过 H1，只懂四分之一的就能过 H3。

| 发现（宽视野，40 世界，有碰撞事件） | 6 盘 | 10 盘 |
|---|---|---|
| 分母 E-P − E-B：噪声 0.25 倍 → 登记值 → 4 倍 | 0.264 → 0.230 → 0.111 | 0.241 → 0.188 → 0.080 |
| S-P：噪声 0.25 倍 → 登记值 → 4 倍 | 0.812 → 0.697 → 0.529 | 0.722 → 0.604 → 0.440 |
| 只懂一半碰撞（每步每对决定一次）的 C | **0.72**（0.45, 0.95） | **1.08**（0.91, 1.30） |
| 只懂四分之一碰撞的 C | 0.43（0.10, 0.74） | **0.71**（0.54, 0.91） |
| 不懂交互、只调噪声（4 倍、0.25 倍）的 C | −0.20、−0.12 | −0.04、0.00 |

## 逐项

### 1. C 在什么错误实现下也能过

| 代用模型 | 6 盘 C | 10 盘 C | 过 H1 吗（6 盘，≥ 0.5） |
|---|---|---|---|
| E-B 加大或减小噪声（不懂交互） | −0.20、−0.12 | −0.04、0.00 | 不过 |
| 常速度 | −0.27 | −0.27 | 不过 |
| 只懂四分之一碰撞 | 0.43 | 0.71 | 点估计不过；10 盘已过 H3 |
| 只懂一半碰撞 | 0.72 | 1.08 | **过** |

- **分母：** 200 个世界时区间半宽约 ±0.036，相对误差约 16%，不至于让 C 失控。门限换成两档敏感性时，分母为 0.207–0.230（6 盘）、0.149–0.188（10 盘），影响不大。
- **负对照：** L-ind 这一条挡得住「只是噪声不同」。E-B 那一条是定义，不是对照（应修 8）。
- **H2：** 部分重复 H1（应修 9）。
- **H3：** 门槛偏松（必修 2）。

### 2. 集合卡尔曼是否公平

- **欧氏门限：** 没有明显偏向哪一种过程模型。
- **噪声：** 不公平之处在过程噪声（必修 1）。
- **S-P：** S-P 偏低主要是噪声造成的（应修 1）。登记噪声下 C 的分母稳定；噪声一变，分母就跟着变。

### 3. 训练增强

见应修 2。最该补的是隐藏轨迹那种「位置偏几格、速度偏 0.5 以上」的输入，它们占过程模型输入的大部分，而且正是重识别要靠的那一段。

### 4. 校准、dev、带宽

依次见应修 3、4、5。

### 5. 文字

- **要改的：**
  - 「剩下的差距在关联上」（应修 1）；
  - 「按定义接近 0」（应修 8）；
  - 「欧氏加膨胀也更差」的原因（应修 10）；
  - H1 的性质写成「学到的交互补上差距」，按必修 2 要改成「对重识别足够」。
- **核过成立的：** 「约是 r0 框架的 2.5 倍」（0.230 / 0.085 = 2.7）、「6 盘时 E-P 6.8 条」。
