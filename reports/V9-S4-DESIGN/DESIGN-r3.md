距离分箱启发式（第一版误称「先知」）：均值用真实物理在带噪输入（可见轨迹量级）上的输出，相当于完美的均值模型；方差按「当前带噪输入里与最近盘的距离」分 7–8 箱，在一半数据上拟合，另一半上评。距离是学生看得到的量，所以这是一个查表的启发式，不是先知。下表是它比常数 σ（在**全部**步上拟合）好多少（nats），括号里是 90% 覆盖率（常数 σ / 启发式）。**这个基线是错的，见下文和「r3 复核后的修订」。**

| 预测对象 | 步的类型 | 6 盘 | 10 盘 |
|---|---|---|---|
| 位置 | 全部 | 0.000（0.90 / 0.90） | 0.000（0.90 / 0.90） |
| 位置 | 碰撞 + 擦边 | −0.001 | 0.001 |
| 速度 | 碰撞 | 0.953（0.67 / 0.78） | 1.008（0.66 / 0.76） |
| 速度 | 碰撞 + 擦边 | 0.195（0.88 / 0.92） | 0.152（0.89 / 0.93） |
| 速度 | 自由 | −0.003（0.95 / 0.94） | 0.004（0.96 / 0.95） |

读法：
- **一步的位置不确定性完全由输入噪声决定**，碰撞在一步之内对位置的影响太小。在位置上设校准门，常数 σ 必过，也没有方差头能胜过它。
- **速度的不确定性集中在碰撞附近：** 常数 σ 在碰撞步上严重过度自信，覆盖率只有 0.66–0.67。
- **但上表的提升主要来自基线拟合在全部步上。** r3 复核把常数 σ 改在碰撞加擦边步上拟合之后：一个常数 σ 本身就比原基线好 +0.168（6 盘）、+0.130（10 盘）；距离分箱启发式相对正确基线只有 +0.027、+0.022（区间含 0）；按真值「碰撞或擦边」分两箱的先知也只有 +0.061（+0.022, +0.104）、+0.112。所以按正确基线定不出有意义的校准门（见「r3 复核后的修订」）。

## 3. 动力学模型

输入：全部圆盘的状态（位置、速度），加上墙和柱的几何。输出：下一步的位置均值和速度均值。L-int-σ 另外输出对数方差。

| 代号 | 模型 | 是否学习 |
|---|---|---|
| E-CV | 常速度 | 否 |
| E-B | 常速度加反弹，懂墙和柱 | 否 |
| E-P | 真实物理（生成器） | 否 |
| L-ind | 每个盘独立的 MLP，输入自身状态和最近墙、柱的相对几何 | 是 |
| L-int | L-ind 加两两消息传递：半径 1.5 内的盘对，消息由相对位置、相对速度算出，求和后进更新；另带一个两两接触头 | 是 |
| L-int-c | 同 L-int，消息在「从发送者指向接收者」的坐标系里算（解析规范化） | 是 |
| L-int-σ | L-int 的均值，加一个方差头 | 是 |

**均值的训练**（L-ind、L-int、L-int-c）：

| 项 | 做法 |
|---|---|
| 训练对 | 从 train 分区的真值状态出发，按下面的规则扰动成 x′，标签是模拟器在 x′ 上走 1、5、10 步的结果 |
| 损失 | 均方误差。接触头用模拟器在 x′ 上的接触日志，二元交叉熵 |
| 优化 | Adam，学习率 1e-3；步数和批大小由探针定，目标每格 ≤ 10 分钟 |
| 种子 | 3 个 |

学的是动力学函数本身。集合成员代表「可能的真实状态」，过程模型要的正是这个。

**扰动规则：**
- 每个盘独立取一种噪声：以 0.3 的概率取可见轨迹量级（位置 σ 0.05，速度 σ 0.2），以 0.7 的概率取隐藏轨迹量级（位置 σ 0.7，速度 σ 0.6）。量级与比例取自复核者量到的滤波器实际输入。
- 每个盘以 0.1 的概率丢掉。
- 每个样本加 Poisson(0.3) 个重影：复制一个随机的盘，位置偏移 σ 0.3。
- 扰动后，重叠的盘交给模拟器的位置修正处理，与滤波器里出现重叠时一样。
- **20% 的样本不加任何扰动**（精确状态）。HD 在精确状态上评，训练里不能一个精确样本都没有。

**方差头**（L-int-σ）：
- 训练对：从加了可见轨迹噪声的真值出发，预测下一步的**真实**位置和速度；
- 损失：高斯负对数似然，位置和速度各一个对数方差；
- 用途：学的是「给定带噪状态时，下一步真实状态的分布」，用于校准的描述量（§5）。它不进主比较。

放进滤波器的描述臂 L-int-σ **预计会变差**，原因已知：方差头里大部分是输入噪声带来的不确定性，而集合的离散度已经表示了这一部分，等于算了两遍。拟合出的位置 σ 约 0.054，是登记位置过程噪声的 5 倍。

**代码约束：** 学习模型不得内置解析的碰撞响应（例如按法向交换速度）。交互只能通过学到的消息传递得到。非作者复核要逐行检查这一条，测试检查模型代码里没有调用世界模块的物理函数。

**数据效率：** L-int 和 L-int-c 另各训练一组 1/8 数据的格子。

## 4. 跟踪器（新模块 `s4/filter.py`）

集合卡尔曼滤波，所有模型共用同一套代码。

**每步的流程：**
1. **预测：** 全部轨迹的成员 m 一起送进过程模型，加上登记的过程噪声（位置 0.01、速度 0.05）。主比较中所有模型的噪声都是这一套。描述臂 L-int-σ 按学到的方差抽样，不加登记噪声。
2. **关联：** 检测与轨迹的集合均值之间算欧氏距离，用匈牙利算法匹配，门限是「0.6 + 1.5 × 隐藏秒数」。未匹配的检测新建轨迹。
3. **更新：** 匹配上的轨迹做扰动观测更新，观测噪声 σ 0.05。

| 参数 | 登记值 |
|---|---|
| 集合成员 | 32 |
| 新建轨迹的速度先验 | 方向均匀、速率 0.6–1.4。**这就是生成器的速率分布，是一项真值输入，在此声明** |

**指标：**
- **重识别：** 物体在 a 步可见，a+1 到 b−1 步不可见，b 步再次可见，两次都被检测到；b 步分到的轨迹就是 a 步那条，算对；
- **「有碰撞」：** a ≤ s < b 的某一步里，接触日志记有这个盘与另一个盘的接触；
- **IDF1：** 整回合按全局最优对应计算。

## 5. 假设、门与主要结果

**动力学门**（全观察的测试序列，从精确真值出发预测一步，只看碰撞那一步的两个当事盘）：

```
D(X) = 1 − err(X) / err(E-B)
```

err 是这些盘的速度误差均值；E-P 的误差为 0，所以 D(E-P) = 1。

| 假设 | 判据 | 数据 | 性质 |
|---|---|---|---|
| **HD（碰撞动力学）** | D(L-int) ≥ 0.8，下界 > 0.7 | 主评测 200 个世界的真值序列，6 盘 | 经验问题；只懂 75% 碰撞的代用模型是 0.75–0.81 |
| **HF（不误报碰撞）** | 擦边步上 L-int 的速度误差均值 ≤ 0.1 × err(E-B，碰撞步)，上界 ≤ 0.15 × 同一值 | 同上 | 经验问题；E-B、E-P 在擦边步上是 0，提前触发的代用模型是 0.24–0.57，约为 err(E-B) 的 19%–44%。HF 把误报控制在碰撞步 E-B 误差的约 10% 以内：复核者扫描的提前触发余量里，0.15 及以上全部被挡，0.05 这种小幅提前（误差比 0.053）会被放过，这是有意容忍的偏差 |
| **HD-x（外推到 10 盘）** | D(L-int) ≥ 0.7，下界 > 0.6；擦边步速度误差均值 ≤ 0.15 × err(E-B) | 外推评测 100 个世界的真值序列，10 盘 | 经验问题。**门槛有意放宽**：只懂 75% 碰撞的代用模型（0.76）能过 HD-x，不能过 HD |

**滤波器门**（重识别，主比较共用登记噪声）：

```
C(X) = (acc(X) − acc(E-B)) / (acc(E-P) − acc(E-B))
```

| 假设 | 判据 | 事件 | 性质 |
|---|---|---|---|
| **H1（对重识别够用）** | C(L-int) ≥ 0.5，下界 > 0.25 | 主评测，有碰撞 | 经验问题。C 会饱和，只懂一半碰撞的代用模型也有 0.72，所以 H1 只回答「够不够用」，不回答「学到了多少交互」，后者由 HD 回答 |
| **H2（交互本身对重识别的价值）** | L-int − L-ind ≥ 0.05，下界 > 0 | 主评测，有碰撞 | L-ind ≈ E-B 时被 H1 蕴含；只有 L-ind 明显好过 E-B 时才提供新信息 |
| **H3（外推后对重识别够用）** | C(L-int) ≥ 0.4，下界 > 0.2 | 外推评测，有碰撞 | 同 H1，只回答「够不够用」 |

**负对照：** L-ind 的 D 下界必须 < 0.5，C 下界必须 < 0.25，否则「碰撞」事件里其实不需要交互，HD、H1 都作废。

**校准（描述量，不设门）：** 见「r3 复核后的修订」。

**主要结果（登记，不设门）：**
- **学习模型自身的速度校准：** 从加了可见轨迹噪声的真值出发，在碰撞步、擦边步、自由步上分别报告 L-int-σ 的下一步速度 NLL 和 90% 覆盖率，并与三个参照比较：在 train 的碰撞加擦边步上拟合的常数 σ、距离分箱启发式、按真值「碰撞或擦边」分两箱的先知；主评测、外推评测都报；
- 滤波器层面的校准：可见轨迹在观测更新前，一步预测集合对真实位置的 90% 覆盖率和 NLL，按模型分别报告；
- 过程噪声 0.25 倍、1 倍、4 倍三档下的 C 与 S-P；
- L-int-c − L-int，含全量和 1/8 数据两档；
- 接触头的 F1，基线是常速度碰撞时间小于一步；
- 1、5、10、30 步预测误差；从扰动输入出发的 D；
- L-int-σ 在滤波器里的重识别；
- 门限两档的敏感性；E-CV、S-P、IDF1。

**统计：**
- 每个事件三个种子取平均，按世界配对 bootstrap，10000 次，95%；
- 比例 D、C 的分子分母一起重采样；
- 另报 Bonferroni，m 为登记的比较数。

**合法性门（失败则整个实验无效）：**

| 门 | 判据 |
|---|---|
| 标签 | 重新出现事件和「有碰撞」由接触日志独立重算一致；学生观察只有位置（字段白名单、未来帧变异测试） |
| 地板 | 有碰撞事件上 E-CV < E-B < E-P |
| 样本数 | 主评测有碰撞事件在预期的 ±25% 内（每 40 世界 261 个）；动力学门的碰撞盘步 ≥ 预期的 75%（每 40 世界 552 个，200 世界约 2760 个） |
| 确定性 | 另一个进程里从落盘的权重重跑一部分世界，轨迹分配与落盘的逐位相同 |

## 6. 分区

| 命名空间 | 用途 |

| `s4p1-final` | final，主评测 200 个世界 + 外推 100 个世界。动力学门、误报门和校准描述量用这些世界的真值序列（全观察） |

## 7. 探针与预算

**探针**（冻结前，只用 train 与 probe）：
- 测训练耗时，定步数；
- E-P 走一遍全流程，确认合法性门、样本数能过；
- **全部学习臂完整跑一遍跟踪评测**，不能只看 1 步误差；
- 学不到 HD 就先修训练，不改门。

**预算：**
- 18 个训练格（3 个均值臂 × 3 种子、L-int-σ × 3、两个 1/8 数据臂 × 3），每格 ≤ 10 分钟；
- 跟踪评测：300 个世界 × 学习臂，每个世界约 1 秒；
- 一次 final 约 3 小时，硬上限 4 小时；
- 本机 MLX CPU，不付费，不用云。

## 8. 次序

1. 本稿送非作者复核。

## 10. 风险

- **门是否由结构决定：**
  - HD 用代用模型标定过，门槛把只懂 75% 碰撞的挡在外面，只对 HD 成立；HD-x 有意放宽，挡不住。
  - HF 挡住提前触发这类误报；用碰撞几何的解析规则代替学习，HD、HF 都测不出来，靠 §3 的代码约束和复核。
  - H1、H3 会饱和，所以只写「够不够用」。
  - 校准不设门：按正确基线，连两箱真先知在 6 盘上也只有 +0.061，定不出有意义的门槛。
- **真值输入：**
  - 智能体位姿；
  - 世界几何；
  - 新建轨迹的速度先验；
  - 训练标签来自模拟器。架构 §6 的「真值只作监督通道」允许这样做，结论限于「有模拟器监督时学到的动力学」。
- **复核者与作者同模型。**

## 实现补记（2026-11-10，冻结前声明）

实现与摸底第五至第九轮之后，以下各项是 §3、§4、§7 没有写定、由实现决定的部分。它们写进预登记，冻结后不再改。门、阈值、分区、扰动规则都没有动。

**训练设备与可复现性：**
- 训练在本机 MLX 的 GPU（Metal）上依次进行，评测、校验和重放都在 CPU 上。§7 写的「本机 MLX CPU」按此更正：仍是本机、不付费、不用云。
- 第九轮按第六轮的写法重训，D、HF 与第六轮在四位小数上相同。确定性门只从落盘权重重放跟踪，不依赖训练能否逐位复现。

**训练写法**（`learned_mlx.py`；摸底第五至第十轮的依据见研究日志 `R20261110-S4-start`；步数 20000、批 256 由探针确认，写进预登记）：

| 项 | 取值 | 为什么 |
|---|---|---|
| 批的构成 | 每批一半（`COLL_SHARE = 0.5`）取自第 1 步有盘—盘接触的样本，其余从同一盘数的样本里均匀取 | 精确样本里只有 3.2% 在第 1 步有盘—盘接触，不过采样时 L-int 的 D 只有 0.44（第五轮） |
| 近失份额 | 0（第七轮试过 0.25、0.33，没有帮助） | 近失的距离与 HF 的擦边定义相同（2R + 0.3）。只读训练池的模拟器标签，不读评测数据；但它是照着评测指标的定义配训练分布，在此声明 |
| 损失各项的权重 | 一步、五步、十步三项为 10、1、1（`ROLLOUT_WEIGHTS`）；接触头的交叉熵权重 0.1 | 过采样后碰撞样本的多步滚动误差压过一步项，自由步误差从 0.017 升到 0.11，HF 过不去；一步项加权后 D 0.837、HF 0.078（第九轮） |
| 梯度裁剪 | 全局范数 10 | 去掉裁剪 HF 反而变差（第十轮：0.094 对 0.078） |
| 学习率 | 1e-3，恒定，不衰减（第八轮的余弦衰减没有帮助） | |
| 消息宽度 | 64（第八轮的 128 略好，但第九轮的一步加权已够过门槛，不再加宽） | |
| L-int-c 的方向软化 | dp / √(|dp|² + 0.01²) | 扰动后的裁剪会把两个盘推到同一个角，单位向量在那里导数无界，第五轮 L-int-c 因此发散（研究日志有复现）。接触距离处模长仍大于 0.999 |
| 非有限即停 | 损失或梯度非有限时，在更新参数之前停下并报错 | 不跳过、不悄悄改写 |
| 单格时限 | 600 秒，在训练循环里检查，超时即失败 | §7 的「每格 ≤ 10 分钟」由此强制 |
| 扰动的实现细节 | 扰动后位置裁剪进场地；丢盘后至少保留两个盘 | §3 没写，在此声明 |
| 1/8 数据格 | train 的前 50 个世界，样本数为全量的 1/8，步数相同 | |
| L-int-σ | 均值取同种子训练好的 L-int 并冻结，只训方差头；样本是加了可见轨迹噪声的真值对下一步真值；步数与均值臂相同 | §3「L-int 的均值，加一个方差头」 |

**运行器的墙钟规则：**
- 写下 final 只读一次标记之前，剩余墙钟必须不少于评测预留。预留 = 探针实测的评测与校验耗时 × 4（final 的世界数是探针的 4 倍）× 1.5。
- 训练耗时的 1.2 倍加评测预留超过 4 小时，`make_prereg.py` 拒绝冻结。
- 评测每完成一个世界就追加落盘，超时后已算完的部分可以复算。

**统计：**
- 比值（D、HF、C）和差值只要分母不为正就是无定义。点估计无定义时没有值；任何一次重采样无定义时不给区间。需要值或区间的门一律按不过算。
- 这比 §5 更保守：§5 没有说重采样无定义时怎么办。

**学生视图：**
- 全部学生跟踪器经 `W.student_view` 读检测，返回字段超出白名单 {t, agent, detections} 就报错。
- 合法性门的未来帧变异：截点之后每步丢掉最后一个检测、其余平移 0.5。截点之前的分配必须不变；截点之后跟踪器必须消费变异后的列表（每个变异后的检测各有一个编号），编号也必须确有变化。
