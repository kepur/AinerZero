## 0. 研究原则（写进每个任务卡）

生物启发只是架构假设，数学是可检验的计算描述，神经网络是实现工具，三者不能互相替代：用了网格编码不代表获得空间智能，用了哈密顿方程不代表理解所有物理，加了因果图不代表掌握因果规律。

**唯一的成功标准**：在受限观察下，用更少经验、更少计算，在更多陌生世界里做出可靠的时空预测与行动，并由独立考场证明。

“最优”是要在同数据、同预算、同观测下比较出来的研究目标，**不是已经证明的性质**。本文每一条设计决定都只是“当前证据下的默认选择”，必须由 §5 与 §8 的对照实验检验。

## 1. 设计决定（相对旧架构的取舍）

| 决定 | 理由与边界 |
|---|---|
| **旧 RSSM/GRU 退出新主线**，只作对照基线 | 这是用户的路线决定。M2 系列只证明了“特定的共享参数路线”在历史记忆与动作能力之间互相干扰。“单一共享隐藏状态是结构性原因”是**受现有对照支持的假说**，不能推出所有 RSSM 都不可能解决。D 仍是既有唯一五门候选，未晋升 |
| **状态结构化**：位姿（李群）+ 不确定性 + 对象图 + 地图 + 各时间尺度潜变量 | 每类信息有自己的数学结构与更新规则。“互不覆盖”只描述**存储布局**，不保证共享编码器或训练梯度之间没有干扰，干扰仍由常设 M2 诊断检验。情景条目必须带编码器/特征版本，编码器一变，旧记忆的兼容性要能检查，不能默认还在同一潜空间 |
| **对称性默认用保持重力方向的 SE(2)×高度**；自由飞行物体用 SE(3) | 地面任务里，重力方向固定，“绕竖直轴旋转 + 水平平移”是合理默认。要区分两件事：主动旋转一个物理系统（重力不跟着转，所以完整 SE(3) 不变是错误先验），和被动换坐标（重力向量一起变换，SE(3) 协变仍然合法）。所以不写成“任何 SE(3) 等变都是错误” |
| **地图即记忆**：度量层 = 随自身运动等变变换的潜在网格；拓扑层 = 情景片段上的图 | Flow Equivariant WM、ESWM、CSCG 在部分可观测与少经验条件下更强（论文结果，非本机）；一个记忆同时服务定位、视野外状态与远程规划 |
| **多时间尺度按 H-JEPA**：每层独立潜空间、自顶向下规划；**每层加本层宏动作的逆动力学项** | H-JEPA 实证分层收益，同文指出纯预测目标会慢特征坍塌。逆动力学是**候选机制，不保证**所有任务的静态信息都不丢失；高层的逆动力学目标是本层宏动作，不是原始动作（§4 式 3–4） |
| **目标函数用潜空间预测（LeWM 式：预测 + SIGReg）**，不以像素重建为主损失 | LeWM 两项目标、约 15M 参数、最高 48 倍规划提速是论文相应基准的描述，非本机收益。加入逆动力学后本项目已不是原两项目标，要单独报告 |
| **解析数学与学习分开**：已知运动学、李群运算、观测模型写成不训练的数学核心；网络只学残差与未知规律 | 减少自由度；数学部分可在训练暂停期间实现与证伪 |
| **网格编码只作诊断探针** | 训练路径积分的网络几乎从不自发出现网格样表示；也不能推出该表示在所有空间任务里都无用 |
| **SE(2) 等变优先靠解析规范化获得**：用 GeometryCore 的估计位姿把**点、对象向量、地图坐标**换到重力对齐的智能体坐标系，再进普通 MLX 网络；等变图网络留给对象间相互作用 | 规范化后可接普通主干（Kaba 等 2211.06489）。严格等变有前提（§4 式 9）。原始 RGB 在没有深度或平面假设时，不能仅凭位姿做任意视点的精确 warp |
| **教师合一**：缓存齐后，把多个冻结教师的特征蒸馏成一个小 MLX 学生编码器；World Mode 只常驻它 | Theia（2407.20179）的论文结果；本机收益待 S5 实测 |
| **世界真值与世界脑信念分开**（r4，来自 v10 并改正） | AWZ 的 WorldSnapshot 只放权威状态，不带置信度或推断量；不确定性、证据引用、推断量只存在于 AinerZero 的信念里。否则推断值会被当成真值写回世界 |
| **事件驱动的稀疏更新**（r4，来自 v10） | 只更新受事件影响的对象，沿依赖图传播，超出范围就退回全量更新。世界侧要求与全量更新逐位一致；世界脑侧要求非劣（§4 式 12–13，§8 E2） |
| **记忆按晋升等级分 FAST/MID/SLOW**（r4，来自 v10） | 与时间尺度分层（L1/L2/L3）正交：FAST = 当前信念与工作状态；MID = 情景库与待验证假设；SLOW = 通过独立测试、版本晋升的技能与规律。教师与 LLM 永远不能直接写 SLOW |
| **模型从小起步**（r4，来自 v10） | 学生从 0.1M–2M 参数起步，有证据再到 2M–10M，确有必要才试 20M–30M。W1 的 9.3 万参数神经模型没有赢过规则基线，这是前车之鉴 |

## 2. 结构

```text
AWZ 运行时（权威世界真值，不是学生输入）
  WorldSnapshot/v1.1 ── 事件日志（Event/v1，含真实性层与 affected_ids）── 世界侧稀疏更新（与全量逐位一致）
      │ 受限传感出口（awz.V9.B1）
      ▼
ObservationPacket/v1.1（payload + 时间白名单 time{sim_hz, t_ticks, dt_ticks, dt_s}；来源 external_derived）
      │
      ▼
感知编码器（可换：C0 符号 → 视觉；外部预训练须声明；视频先经 RLT 去停帧重复块）── 检测句柄（遮挡后重发）
      │
      ▼
NeuroGeometry 核心（不训练）：李群运算 · 切空间高斯信念 · 已知运动学预测 · 观测模型 · 位姿图（含规范与锚点）
      │                         ▲ 残差（只作用于连续状态量）
      ▼                         │
解析规范化：点/对象向量/地图坐标按估计位姿换到重力对齐的智能体坐标系（输出再换回）
      │
      ▼
L1 快速层：连续时间 SSM（显式 dt）+ 对象交互（重力对齐等变图网络）── 学残差与未知规律
      │   └─ 世界脑侧稀疏更新：只更新受影响对象的信念，超出范围退回全量
      ├──► 度量地图记忆（FAST/MID）：以智能体为中心、按自运动等变变换的潜在网格
      ├──► 情景库（MID）：地点·时间·对象·动作·来源·编码器版本 键的稀疏转移片段 ──► 拓扑地图
      │                                                         └──► 巩固（回放 + 学习保护）──► SLOW（经独立测试晋升）
      ▼
L2 事件层（H-JEPA 第二层，本层宏动作；步幅 2 起，后比较学习式事件边界）
      ▼
L3 慢速层（仅 L2 过门后加）
      ▼
分层规划（上层预测作为下层子目标）── 学习进展 / 信息增益 ──► SkillProposal（经 AWZ 门禁与统一变更信封）
```

- 每层损失：JEPA 预测 + SIGReg + 本层宏动作的逆动力学（§4 式 4）。
- 位姿与不确定性由数学核心维护；学到的残差只能通过流形上的合法更新作用于位姿，**只作用于连续状态量**，离散事件（碰撞、接触开始与结束、出现与消失）单独预测。
- 情景库是非参数存储，写入不改任何网络参数；检索先用手工线索（时间、位姿、地点、对象），再比较 FAR 式学习检索。
- 规范化用的是**估计**位姿：训练时按 GeometryCore 的协方差注入位姿误差；评测时分别报告“真值位姿规范化”（上界，仅诊断）与“估计位姿规范化”（正式成绩）。
- 记忆实现候选（S3 再比较，均为假设）：
  - 非参数情景库（默认）；
  - Titans 式测试时神经记忆（2501.00663）；
  - Nested Learning 式多频率更新（2512.24695）。
  任一候选只要改动参数，就必须过式 6 的学习保护约束，并报告 M2 记忆干扰诊断。
- Teacher Gateway：教师断言、示范与自身经历分通道，仿真真值只作 `sim_truth` 监督通道，来源 `simulator_truth`，分区仍为四值；关掉所有 LLM，学生仍能运行。

## 4. 数学定义

**约定**（GeometryCore 与 G1 共用，r4 起写死）：
- 位姿 `T_AB` 表示“把 B 坐标系中的点变到 A 坐标系”，因此 `p_A = T_AB · p_B`，`T_AC = T_AB · T_BC`。
- 误差用**右扰动**：`T = T̂ · Exp(ξ)`，`ξ ∈` 切空间。
- 协方差在坐标系之间按 Adjoint 变换：`Σ_A = Ad(T_AB) Σ_B Ad(T_AB)ᵀ`。
- **规范与锚点**：首帧位姿（或登记的锚点）固定为规范，不可观测的自由度（全局平移、绕重力轴的全局朝向，单目时还有尺度）必须显式声明，不能当作已估计的量。

1. 相对位姿：`T_AB = T_WA^{-1} T_WB`；旋转在 SO(3)/SO(2) 上合法更新。
2. 切空间高斯信念：`x = μ ⊕ ξ, ξ ~ N(0, Σ)`；预测 `μ' = μ ⊕ f(u, dt)`，`Σ' = F Σ Fᵀ + Q(dt)`，更新按不变 EKF 形式。
   - **误差界的前提**：高斯噪声无界，非线性 EKF 一般没有确定性的全路径误差界。
   - 解析误差界只在写明的前提下成立：可观测、线性或有界噪声、已知运动学。
   - 一般情形只报告统计校准与误差分布，例如 NEES 覆盖率。
3. 分层潜在动力学：`z^{(k)}_{t+s_k} = F_k(z^{(k)}_t, a^{(k)}_t, Δt_k)`。
   - **宏动作**：`a^{(k)} = A_k(a^{(k−1)}_{t:t+s_k})`，`A_k` 是登记的聚合规则，例如位移总和、朝向变化、动作类别直方图；
   - `Δt_k` 是这 `s_k` 步的实际时长之和，以适应不规则 `dt`；
   - 上层回归 `sg(a^{(k)})`，即停止梯度后的宏动作；
   - 若宏动作由网络编码（`a^{(k)} = e_ψ(·)`），`e_ψ` 自身也要防坍塌（例如对动作嵌入另加 SIGReg），这一点按 H-JEPA §4.3、C.2 的做法。
4. 每层损失：`L^{(k)} = L_pred + λ SIGReg(Z^{(k)}) + μ L_IDM^{(k)}`，其中 `L_IDM^{(k)} = −log p(sg(a^{(k)}) | z^{(k)}_t, z^{(k)}_{t+s_k})`。
   - 目标是**本层宏动作**，不是每层都预测同一个原始动作；
   - 目标维度与本层宏动作一致。
5. 等变地图记忆：`M_{t+dt} = g(Δpose) · M_t ⊕ write(o_{t+dt})`，`g` 为 SE(2) 作用。
6. 学习保护：`min L_new(θ)` s.t. `L_old(θ) ≤ L_old(θ_baseline) + ε`（ε、基线在登记时冻结）。
7. 信息增益：`a* = argmax_a I(S; O_next | a)`（近似）。
8. 混合物理：`s_{t+dt} = F_prior(s_t, a_t, dt; φ̂) ⊕ r_θ(local_graph, event, history)`。
   - 残差只作用于连续状态量；离散事件单独预测；
   - 虚构世界规律带机制 ID 与作用域；
   - **先验必须登记它与真实世界的偏差来源**，例如参数 `φ̂` 未知或随机化、无摩擦、接触近似。若先验与生成数据的模拟器完全相同，残差没有可学的东西，这个对照就没有意义（§8 E1）。
9. 解析规范化：`x̃ = g(μ̂)^{-1} · x`，`y = g(μ̂) · f_θ(x̃)`，`g(μ̂) ∈ SE(2)` 是估计位姿保持重力方向的部分。
   - **严格等变的前提**：估计器 `μ̂` 本身与输入的群作用一致，即 `μ̂(g·o) = g·μ̂(o)`，并且 `x` 是已定义群作用的量（点、对象向量、地图坐标）。
   - 离散栅格的插值与边界、数值误差、数据关联错误都会破坏精确等变，所以报告等变误差时要分别列出这几项来源；
   - 原始 RGB 不在此列。
10. RLT 停帧去重：同一位置的图块若 `‖p_t − p_{t−1}‖_∞ < τ` 就并入上一个 token，并以游程长度编码位置；`τ` 在登记时冻结，报告 token 保留率与精度损失。
11. 教师表示对齐（仅 S5 及其消融）：`L_align = 1 − cos(h_φ(z^{(l)}), sg(T(x)))`；`T` 为冻结教师，`h_φ` 为小投影头；总损失加 `η L_align`，`η` 登记时冻结。
12. 稀疏更新（r4）：
   - 依赖图 `G_t`：边来自接触、附着、距离 < `r_dep`、可见性关系；
   - 脏集合 `D_t = N_k(S_t; G_t)`，其中种子 `S_t` = 本步受动作、接触变化、遮挡变化、新观测影响的对象，加上信念不确定性增长超过 `u_max` 的对象，`N_k` 是 `k` 跳邻域；
   - 若 `|D_t| / |V| > f_max`，或误差监测超限，就全量更新；
   - `k`、`r_dep`、`u_max`、`f_max` 都在登记时冻结。
13. 非劣检验（r4）：稀疏更新相对全量更新的误差差值 `Δ = e_sparse − e_full`，用按回合的配对 bootstrap 取 95% 置信区间上界 `U`；`U ≤ δ` 才判非劣，`δ` 登记时冻结。

## 5. 研究顺序与门槛

**S1 的共同口径（r4）**：
- 新空间任务与 C0 兼容诊断，要先定义**共同的观察与输出**：
  - 观察用 ObservationPacket/v1.1 的同一组通道；
  - 输出是位姿、位置、事件，并写明单位与坐标系。
- D 候选的旧 C0 指标不能直接当作新 3D 任务的成绩。
- 指标：
  - 定位误差、未见地图泛化、混淆观察下的拓扑恢复、少经验预测未见转移、样本效率曲线；

**常设对照（每个阶段都要）**：
- M2 系列的记忆干扰诊断（零状态/历史配对、动作保持）对新模型原样报告，与 D 候选同表；
- 新结构若“看起来解决了”却在这组诊断上无改善，视为未过门；
- 若因观察或输出不同而**不可比**，必须显式写出，并**阻断**相应的能力结论，不能默认通过。

## 7. 本机集成：M2 Max 96GB、无 CUDA

- 本机实测：MacBook Pro M2 Max（38 核 GPU）、96 GB 统一内存；两个项目环境均为 MLX 0.32.x，**未安装 PyTorch**。凡依赖 PyTorch MPS 的组件都需先经用户批准安装。
- 原则：**离线教师 + 特征缓存 + 原生 MLX 小型学生 + Blender/物理引擎仿真真值**；不移植 CUDA 项目，教师不常驻内存。
- **保护线不借“规划值”改写**：内存、磁盘、电源保护线（ADR-0006 第 5 条、ADR-0009 第 4 条）与各卡登记的上限照旧。用电池时不跑训练与重任务。

### 7.1 运行模式（以 `docs/v9/TEACHERS_AND_CACHE.md` r1 为准）

| 模式 | 常驻 | 规则 |
|---|---|---|
| Teacher Mode | 单个教师模型 | 整段持有 `artifacts/locks/m0-worker.lock`；与训练互斥 |

### 7.2 教师 = 带噪声的传感器

几何教师（DA3 相机位姿与深度、Depth Anything 相对深度）的输出存在尺度歧义，**不是真值**：
- 作为观测接入 GeometryCore 的信念更新（§4 式 2）；
- 噪声模型在合成数据上用真值标定，并按场景类型分别登记（TEACHERS_AND_CACHE §4）。

视频特征教师（V-JEPA 2.1）只作感知特征与预测目标的对照。

**里程碑**：v10 的“第 1–3 天 / 第 4–7 天 / 第 8–14 天 / 第 3–6 周”只作顺序参考。
- 可以先做、不需训练的：E0 生成器设计与 CPU 小样、E2a、E3 回放；
- E1、E2b、E4、E6 都要等用户批准训练或下载。

### 8.4 成本模型

`T_total = T_data_generation + T_teacher_extract + T_train + T_eval + T_engineering`；节省 `= 1 − T_total(方案) / T_total(基线)`。
- 只在相同数据、任务和目标质量下比较；
- 没有 M2 Max 实测基准前，不承诺任何训练时长或成本；
- 从零训练大型基础模型不是等价质量的基线。

### 8.5 不做事项

- 首版不移植 Cosmos、WorldForge 的完整 CUDA 链；
- 不把 3DGS 当作物理或语义世界状态；
- 不允许教师未经验证直接修改长期知识（SLOW）；
- 不承诺实时生成开放世界或 Genie 级画质。
