# ARCHITECTURE_V9 r3 平级审议（Codex，2026-10-16）

结论：**方向同意；当前r3不足以冻结为训练协议，需r4修订后平级复核。** 本轮审的是实际r3，不是卡面旧r2。仅只读审议与原始文档身份登记，无CPU模型实验、无训练、无RunStore或预算登记；原D/M2失败完整保留。待修订不是否定结构化状态/地图/分层路线，也不是恢复旧RSSM主线。

## 逐节判断与强制修订

| 章节 | 判断与具体修订 |
|---|---|
| §0 研究原则 | 同意；“最优”是需要同预算比较的研究目标，不是已经证明的性质。 |
| §1 RSSM退出、调研§0.1 | 退出新主线是用户路线决定，合理；M2只证明特定共享参数路线冲突。把“单一GRU正是结构性原因”降为受现有对照支持的假说，不能推出所有RSSM不可能解决。D仍是既有候选，未晋升。 |
| §1/§2 结构化状态 | 同意显式位姿/不确定性/地图；“互不覆盖”只描述存储布局，不保证共享编码器/训练梯度无干扰。情景条目需带编码器/特征版本，编码器变更时旧记忆兼容性必须可检查，不能默默解释成同一潜空间。 |
| §1 重力与群 | 地面任务选保持既定重力方向的SE(2)是合理默认；区分主动旋转物理系统与被动换坐标。重力向量一起变换时SE(3)坐标协变仍合法，不应写成“任何SE(3)等变都是错误”。 |
| §2/§3 GeometryCore、式2/9 | 先声明T_AB方向、左/右切空间误差、协方差的Adjoint变换、gauge/锚点与不可观测自由度。式9严格等变的前提是估计器和输入群作用一致；离散栅格插值/边界、数值误差、数据关联也会破坏精确等变，删去“误差只来自位姿估计”。原始RGB没有深度/平面假设时不能仅凭位姿做任意视点精确warp；精确性质仅承诺已定义群作用的点/对象向量/地图坐标。 |
| §2/§4/§5 H-JEPA、式3/4 | 分层各自潜空间和自顶向下子目标有论文支撑；高层IDM的目标必须是本层宏动作，不能各层都预测同一个primitive action。定义宏动作聚合、detach、目标维度与不规则dt对齐；学到的宏动作编码还需防自身坍塌，不能仅写一个预测损失就宣称排除。IDM是候选机制，不保证所有任务静态信息不丢失。 |
| §3 Observation输入、§7.4 sim_truth | dt必须进入模型实际能消费的最小时间白名单；不得传整信封。sim_truth仅监督通道，partition仍四值，source_type沿用simulator_truth；与awz.V9.A2/forge.V9.A1对齐。 |
| §5 S0 | 同意CPU数学优先；高斯噪声无界，非线性EKF也无任意条件全路径确定性误差界。解析界必须附可观测性、线性/有界噪声等前提；一般情形报告统计校准/误差分布。G1已要求先登记CPU容差与fixture，不能把CPU工程界替代S1科学门。 |
| §5 S1/S2与常设M2对照 | 空间→多时间尺度顺序与用户最新决定一致；需定义C0兼容诊断/新空间任务共同观察与输出，D的旧C0指标不能直接当新3D成绩。M2动作保持/历史诊断保留，任何不可比必须显式阻断能力结论。解析/学习等变、优化器、多步、多频更新逐项预登记，不默认展开全因子搜索或复用预算。 |
| §5 S3–S6 | 延后检索、对象、视觉学生训练与自驱合理；S2成功前不加L3，外部预训练和真值监督分别标明，不把文献结果当本机能力。 |
| §7 T/Train/World | 三模式方向合理，但T1现文存在试锁释放竞态、World与Train互斥缺口及CoreML共存矛盾；已退回T1。缓存输出blob与逐世界/分区来源记录需分开身份，不能同键覆盖来源；T2仅在修订通过后实现。现有保护线不得借“规划值”改写。 |
| 调研与引用 | H-JEPA/LeWM/规范化来源本轮直接打开一手页面；R2已揭THICK官方代码缺失断言错误、Stable WorldModel日期错、V-JEPA2.1论文版本遗漏，R1已退回。未核条目保留未知，不把作者代码MIT扩展为所有权重/数据集许可。 |

## 本轮直接核对的一手来源

- [H-JEPA v1](https://arxiv.org/html/2610.06805v1)，§4.3、C.2、K/L：分层规划及IDM的证据有条件；上层回归detach后的宏动作，并对动作嵌入另作防坍塌。DROID结果是离线规划忠实度，不是闭环机器人成功率。本文只借鉴机制，未运行代码。
- [Equivariance with Learned Canonicalization Functions](https://arxiv.org/abs/2211.06489)：规范化可接普通主干的来源成立；不能据此证明本项目估计器、栅格离散化或RGB任意warp已满足等变前提。
- [LeWM官方代码说明](https://github.com/lucas-maes/le-wm)：两项目标及约15M/最高48倍是论文相应基准描述，非本机收益；加入IDM后本项目已不是原两项目标，需单独报告。
- [网格调谐反证论文](https://arxiv.org/abs/2312.03954)：网格样表征不作成功标准合理；不推出所有空间任务中该表征都无用。
