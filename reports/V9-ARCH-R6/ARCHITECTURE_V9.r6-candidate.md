## 0. 研究原则（写进每个任务卡）

生物启发只是架构假设，数学是可检验的计算描述，神经网络是实现工具，三者不能互相替代：用了网格编码不代表获得空间智能，用了哈密顿方程不代表理解所有物理，加了因果图不代表掌握因果规律。

**唯一的成功标准**：在受限观察下，用更少经验、更少计算，在更多陌生世界里做出可靠的时空预测与行动，并由独立考场证明。

“最优”是要在同数据、同预算、同观测下比较出来的研究目标，**不是已经证明的性质**。本文每一条设计决定都只是“当前证据下的默认选择”，必须由 §5 与 §8 的对照实验检验。

**证据状态（r6）**：§1 的每条决定都带一个状态，只取五个值。

| 状态 | 含义 |
|---|---|
| 有支持 | 至少一次登记运行的门，或已经独立复算的描述量支持它；同时写明成立的范围 |
| 部分支持 | 只在机制、契约或某个子问题上成立 |
| 被削弱 | 登记运行的结果与默认选择相反，默认选择已经改掉 |
| 未检验 | 还没有登记运行回答过 |
| 执行缺口 | 架构要求了，实际没有照做 |

状态只描述「在做过的小世界里看到了什么」。到 r6 为止，所有证据都来自合成的小世界（GridLab、二维圆盘、合成视频）。没有一项是能力晋升，也没有一个模型同时具备其中两项以上的能力（§14）。

## 4. 数学定义

**约定**（GeometryCore 与 G1 共用，r4 起写死）：
- 位姿 `T_AB` 表示“把 B 坐标系中的点变到 A 坐标系”，因此 `p_A = T_AB · p_B`，`T_AC = T_AB · T_BC`。
- 误差与协方差的约定**直接引用 G1**（`src/ainerzero/v9/geometry/belief.py`）：
  - 右误差 `X = μ · Exp(ξ_r)`，左误差 `X = Exp(ξ_l) · μ`；
  - 两者关系 `ξ_l = Ad(μ) ξ_r`，所以 `P_l = Ad(μ) P_r Ad(μ)ᵀ`（一阶矩）。
- 这条 Adjoint 只用于**把同一个切向量从右误差改写为左误差**，不能当作任意换世界坐标系时右误差协方差的变换。纯左乘的世界坐标变换下，右误差 `ξ_r` 不变，协方差也不变。B2、G3 的实现以 G1 为准，不另作解释。
- **规范与锚点**：首帧位姿（或登记的锚点）固定为规范，不可观测的自由度（全局平移、绕重力轴的全局朝向，单目时还有尺度）必须显式声明，不能当作已估计的量。

1. 相对位姿：`T_AB = T_WA^{-1} T_WB`；旋转在 SO(3)/SO(2) 上合法更新。
2. 切空间高斯信念：`x = μ ⊕ ξ, ξ ~ N(0, Σ)`；预测 `μ' = μ ⊕ f(u, dt)`，`Σ' = F Σ Fᵀ + Q(dt)`，更新按不变 EKF 形式。
   - **误差界的前提**：高斯噪声无界，非线性 EKF 一般没有确定性的全路径误差界。
   - 解析误差界只在写明的前提下成立：可观测、线性或有界噪声、已知运动学。
   - 一般情形只报告统计校准与误差分布，例如 NEES 覆盖率。
3. 分层潜在动力学：`z^{(k)}_{t+s_k} = F_k(z^{(k)}_t, a^{(k)}_t, Δt_k)`。
   - **宏动作**：`a^{(k)} = A_k(a^{(k−1)}_{t:t+s_k})`，`A_k` 是登记的聚合规则，例如位移总和、朝向变化、动作类别直方图；
   - `Δt_k` 是这 `s_k` 步的实际时长之和，以适应不规则 `dt`；
   - 上层回归 `sg(a^{(k)})`，即停止梯度后的宏动作；
   - 若宏动作由网络编码（`a^{(k)} = e_ψ(·)`），`e_ψ` 自身也要防坍塌（例如对动作嵌入另加 SIGReg），这一点按 H-JEPA §4.3、C.2 的做法。
4. 每层损失：`L^{(k)} = L_pred + λ SIGReg(Z^{(k)}) + μ L_IDM^{(k)}`，其中 `L_IDM^{(k)} = −log p(sg(a^{(k)}) | z^{(k)}_t, z^{(k)}_{t+s_k})`。
   - 目标是**本层宏动作**，不是每层都预测同一个原始动作；
   - 目标维度与本层宏动作一致。
5. 等变地图记忆：`M_{t+dt} = g(Δpose) · M_t ⊕ write(o_{t+dt})`，`g` 为 SE(2) 作用。
6. 学习保护：`min L_new(θ)` s.t. `L_old(θ) ≤ L_old(θ_baseline) + ε`（ε、基线在登记时冻结）。
7. 信息增益：`a* = argmax_a I(S; O_next | a)`（近似）。
8. 混合物理：`s_{t+dt} = F_prior(s_t, a_t, dt; φ̂) ⊕ r_θ(local_graph, event, history)`。
   - 残差只作用于连续状态量；离散事件单独预测；
   - 虚构世界规律带机制 ID 与作用域；
   - **先验必须登记它与真实世界的偏差来源**，例如参数 `φ̂` 未知或随机化、无摩擦、接触近似。若先验与生成数据的模拟器完全相同，残差没有可学的东西，这个对照就没有意义（§8 E1）。
9. 解析规范化：`x̃ = g(μ̂)^{-1} · x`，`y = g(μ̂) · f_θ(x̃)`，`g(μ̂) ∈ SE(2)` 是估计位姿保持重力方向的部分。
   - **严格等变的前提**：估计器 `μ̂` 本身与输入的群作用一致，即 `μ̂(g·o) = g·μ̂(o)`，并且 `x` 是已定义群作用的量（点、对象向量、地图坐标）。
   - 离散栅格的插值与边界、数值误差、数据关联错误都会破坏精确等变，所以报告等变误差时要分别列出这几项来源；
   - 原始 RGB 不在此列。
10. RLT 停帧去重：同一位置的图块若 `‖p_t − p_{t−1}‖_∞ < τ` 就并入上一个 token，并以游程长度编码位置；`τ` 在登记时冻结，报告 token 保留率与精度损失。
11. 教师表示对齐（仅 S5 及其消融）：`L_align = 1 − cos(h_φ(z^{(l)}), sg(T(x)))`；`T` 为冻结教师，`h_φ` 为小投影头；总损失加 `η L_align`，`η` 登记时冻结。
12. 稀疏更新（r5 拆成两式）：
   - **12a 世界侧（AWZ）**：更新集合 `U_t = closure( A_t ∪ S_t ∪ C_t ; G_t )`。
     - `A_t` 是活跃集合：速度非零、受持续外力、有计时器或脚本运动、处在未结束约束中的对象；
     - `S_t` 是本 tick `actual` 且 `state_effect` 的事件的 `affected_ids`；
     - `C_t` 是对 `A_t ∪ S_t` 做宽相检测得到的可能新接触；
     - `closure` 是在约束图 `G_t`（接触、附着、支撑、包含）上的传递闭包，不是固定跳数。
     - 不在 `U_t` 的对象必须严格不变，或可按登记的解析规则逐位等价地延迟求值；做不到就放进 `U_t`。
     - 闭包占比超过 `f_max`、宽相无法给出上界、或校验不一致时全量回退。
     - 正确性只在登记的确定性域（Blender 构建、Bullet 求解器、步长、平台、输入）内按状态哈希逐位一致检验（Event/v1 §4.1–§4.3）。
   - **12b 学习侧（AinerZero）**：种子只来自允许观察中的变化、学生已执行的动作、信念不确定性增长超过 `u_max` 的对象；依赖图只由信念推出；扩展比例超过 `f_max` 时全量更新。
   - 所有阈值（`f_max`、`u_max` 等）在登记时冻结。
13. 非劣检验（r4）：稀疏更新相对全量更新的误差差值 `Δ = e_sparse − e_full`，用按回合的配对 bootstrap 取 95% 置信区间上界 `U`；`U ≤ δ` 才判非劣，`δ` 登记时冻结。
14. 规划代价（r6）：规划器最小化的是独立登记的代价 `c(b, g)`，其中 `b` 是信念、`g` 是目标；不默认取 `‖z − z_g‖`。
   - **可达性代价**：`c_ψ(b_t, g) ≈ d*(s_t → g)`，`d*` 是到达目标最少要走的步数或时长。
     - 监督来自训练轨迹的事后重标：同一条轨迹上 `t < t'` 的两个时刻给出 `d* ≤ t' − t`。
     - 这只是上界。要靠拟度量结构、时序差分或跨轨迹拼接去逼近最短，不能把 `t' − t` 直接回归出来就当作 `d*`。
   - **图上代价**：把情景库的拓扑图或度量地图上的栅格图记作 `G`，`c(b_t, g) = dist_G(node(b_t), node(g))`。节点匹配用估计位姿；匹配并列和匹配失败都要计数。
   - **诊断三项**，冻结前在真正训练过的模型上实测，登记为前置：
     - `ρ = Spearman(c, d_true)`，代价与真实远近的秩相关；
     - 一步预测误差与「原地不动」误差之比；
     - 短目标成功率。
     三项的最低要求在预登记里定，任何一项不达标就不进入长目标运行。
   - 真值距离 `d_true` 只用于这三项诊断和上界臂，不进入学生输入。
   - 可参考的做法都是论文结果，本机没有复现：拟度量强化学习（2304.01203）、Hilbert 表示（2402.15567）、由对比后继特征得到的时间距离（2406.17098）。
15. 多步目标（r6）：`L_roll = Σ_{h=1..H} w_h · ℓ(ŝ_{t+h}, s_{t+h})`，`ŝ` 由模型拿自己的输出滚动得到。
   - `H` 不小于评测步长；做不到时，至少按评测步长上的滚动误差选模。
   - 只用一步损失训练的臂保留作对照。
16. 门控混合（r6，细化式 8）：`s_{t+dt} = F_prior(s_t, a_t, dt; φ̂) ⊕ m_t · r_θ(·)`，`m_t = 1[q_ω(local_graph) > τ]`。
   - `q_ω` 是事件头，例如接触头；`τ` 登记时冻结。
   - 必须报告四项：门打开的比例；误开的代价，即没有事件的样本上相对先验退化多少；门开时乱猜方向的对照；同样开门比例的随机门对照。
   - `m_t ≡ 1` 是 r5 的写法，保留作对照臂。
17. 自驱分数（r6，补充式 7）：
   - 已知机制：`u(x) = Var_k[f_{θ_k}(x)]`，即集成分歧，或 epinet 的等价量。
   - 新机制：`u(x) = ℓ(f_{θ⁺}(x), y)` 按上下文累计，例如按布局。`θ⁺` 是当前已晋升的版本，不是正在训练的候选；对着正在训练的候选算，信号会自己熄掉。
   - 采样：按 `u` 选的占 `1 − ε`，随机保底占 `ε`，另给常见情形留登记的最低份额。`ε` 与份额登记时冻结。

### 5.3 冻结前置检查（r6，写进每份预登记）

这几条都来自已经付过代价的失败，补在「预登记规则（r4）」之后。

1. **完整协议先跑通两遍**：一遍用完美假臂，一遍用真正训练过的模型，短训即可。S2 最初登记的规划协议，连完美模型都到不了长目标，冻结之后才发现。改过协议之后完美假臂能过，但它的隐空间就是真实状态，测不出「训练后的隐空间能不能当代价」。
2. **在登记规模上实测每一条路径的耗时**，评测阶段也算在内。S5 第一次登记运行里，RLT 稀疏分支被形状抖动拖慢，撞上了单格上限；它的评测阶段不受时限管，超出批准预算约 0.3 小时。
3. **便宜基线与真值依赖清单写进设计稿**（§1）。
4. **最优臂按多个档选**，不按单一最低档。S5 按 64 段标签档选出的臂，在更高的两档里是三个教师臂中最差的。
5. **区间判据先估重复间的波动**。S6 一期的 GK-F 点值在门内，但 5 个重复的区间上界超了。
6. **最终数字由非作者独立复算**，这已经是惯例，在这里写明。

### 8.4 成本模型

`T_total = T_data_generation + T_teacher_extract + T_train + T_eval + T_engineering`；节省 `= 1 − T_total(方案) / T_total(基线)`。
- 只在相同数据、任务和目标质量下比较；
- 没有 M2 Max 实测基准前，不承诺任何训练时长或成本；
- 从零训练大型基础模型不是等价质量的基线。

### 8.5 不做事项

- 首版不移植 Cosmos、WorldForge 的完整 CUDA 链；
- 不把 3DGS 当作物理或语义世界状态；
- 不允许教师未经验证直接修改长期知识（SLOW）；
- 不承诺实时生成开放世界或 Genie 级画质。

### 8.6 学习侧的信息边界（r5，F2）

世界真值不能从“调度路径”或“资产引用”间接进入模型：
- **三类事件分开**：
  - 世界事件（Event/v1）只给世界侧；
  - 观察事件（ObservationPacket 里的 `audio_events` 等）对学生可见；
  - 信念事件只在世界脑内部。
- **学习侧调度**：只读允许观察、学生已执行动作、自身信念（§3 `UpdateScheduler`）。世界侧的脏集合、对象 ID、图边、回退标志都不能以任何形式传给学生。
- **截至时刻的引用解析**：
  - payload 里可被模型触及的 URI 与内容摘要，只能解析到允许的命名空间，并且是截至本包 `t_ticks` 已存在的资产；
  - 指向 `private/`、评测通道、未来 tick 或真值文件的引用一律拒绝；
  - 要在**实际加载路径**上测试，不只测字段（awz.V9.A3、B1 卡已写入）。
- **教师输入**：用作输入的教师特征，输入片段不得晚于截止时刻（TEACHERS_AND_CACHE r2 的 `as_of_t_s`）；未来帧只能作隔离的预测标签。
- **必要反例**：两个世界在 `t` 以前给学生的观察完全相同、隐藏的未来不同，学生在 `t` 时刻的模型输入、学习侧调度出的更新集合、能解析到的资产都必须相同。

## 14. 距离 §0 成功标准还差什么（r6）

§0 的标准是：在受限观察下，用更少经验、更少计算，在更多陌生世界里做出可靠的时空预测与行动，并由独立考场证明。逐项对照：

| 标准里的部分 | 现有证据 | 差距 |
|---|---|---|
| 受限观察 | 各阶段都用受限或结构化的观察；S5 用合成视频 | 多处还有特权输入：真值位姿、真值路由、手写规则、结构化检测 |
| 更少经验 | S6 一期：同样 12000 个标签，自选样本的碰撞预测高 0.095 | 没有跨方法的样本效率曲线；S5 的教师在最低标签档几乎没有帮助 |
| 更少计算 | 世界侧稀疏更新的参考实现；RLT 让蒸馏每步省 11% | §8.4 的完整成本从来没有算过 |
| 陌生世界 | 从 6 个盘外推到 10 个盘成立（S4、S6） | 外观一换全崩（S5）；没有真实视频；「出现新规律」还在设计阶段（S6 二期） |
| 可靠的预测 | 碰撞动力学 D 0.87；一步覆盖率校准 | 重新出现那一刻的校准没有过；墙柱靠手写规则；E1 的多步预测没有过 |
| 行动 | 没有 | 长目标成功率是 0；规划代价没有解决 |
| 独立考场 | final 只读一次、非作者独立复算，已是惯例 | S2–S6 的考场都是各阶段在本仓库里自建的小世界 |

三条没有打通的连接，按紧迫程度排：

1. **预测到行动**：完全空白。先做 §5.2 的 P 阶段。
2. **新知识到旧技能保留**：机制在非参数存储上成立，参数化的版本还没有做。S6 二期正在回答。
3. **简单世界到陌生世界**：对象数量能外推，外观不能。视觉前端要先过换域门。

在这三条之外，还有一个结构性的缺口：每个阶段各自过门，没有一个阶段要求把预测、记忆、规划接在同一个模型上。§5.2 的 I1–I3 就是为了补它。先后顺序只是建议，不是授权。
