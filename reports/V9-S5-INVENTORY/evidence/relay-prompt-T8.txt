## 任务说明
按 ARCHITECTURE_V9 r3 §4 式 10，在 `src/ainerzero/v9/tokenization/rlt.py` 实现 RLT 停帧去重的 numpy 参考实现。
来源：Choudhury 等，Run-Length Tokenization，arXiv 2411.05222；只读论文，不下载其代码。

功能：
- 输入视频块序列 `[T, H/p, W/p, D]`；同一位置若 `‖p_t − p_{t−1}‖_∞ < τ` 就并入上一个 token；
- 输出保留 token、各 token 的游程长度与原位置索引，并能无损还原到每帧块网格（被并入的块用上一 token 填回）；
- 报告 token 保留率。

合成测试片段（程序化生成、固定种子，不下载任何视频）：
- 动漫式有限动画：一拍一、一拍二、一拍三；
- 局部动作（只有嘴/手在动）；
- 镜头平移（几乎没有可去重的块）；
- 全静止；
- 带编码噪声的“伪静止”（τ 敏感性）。

测试：
- 还原误差 ≤ τ；
- 保留率与片段的理论值一致（一拍二约 1/2，全静止约 1/T）；
- τ = 0 时不去重；
- 位置与游程长度编码可逆；
- 输出确定性。

故意改坏必须变红：比较方向错一帧、游程长度少计 1、忽略首帧。

交付：`reports/V9-T8/REPORT.md`，写明各片段的保留率表和 τ 敏感性曲线（数值表即可）。在 V-JEPA 2.1 特征上的 GPU 实测（精度损失 vs 吞吐）不在本卡，等 T4 验收后由一级另提预算。

研究原则：生物启发只是架构假设，数学是可检验的计算描述，神经网络是实现工具，三者不能互相替代；唯一成功标准是受限观察下用更少经验、更少计算在更多陌生世界里做出可靠时空预测与行动。
