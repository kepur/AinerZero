## 2. 项 1：views 预检前移 + 派生路径补测

### 2.1 代码

`da3_controlled.py` 里 `action` 依赖 `is_released`，而 `is_released` 原先在 Step 7 才解析、预检又排在 Step 6 之后。改法是把**纯计算**整体前移，副作用顺序不变：

```
Step 6a (新): is_released 解析 + test_substitute 守卫 + action 派生 + effective_allow_model   ← 纯计算
Step 6b (新): action == "real_pipeline" 且 views != REGISTERED_CALIBRATION_VIEWS -> 立即拒
Step 6  (原): 累计配额 + 累计墙钟预算
Step 7  (原): 未放行拒（is_released 已在 6a 算好）
Step 8  (原): 硬件资源门
```

- 前移的三段都**不读台账、不碰锁、不建 RunStore**，所以"零扣账、零锁、零 worker 启动"不变；
- 预检对**派生路径**（`worker_action=None` + `is_released`）与显式 `worker_action="real_pipeline"` 走**同一条门**；
- 拒绝详情新增 `derived_from_release`（True = 由放行标志派生），便于事后区分"显式请求真跑"与"标志派生真跑"。

## 5. 必须请复核方拍板：T43 F-3 的前提不成立，M-B 在原代码上是**等价变异**

这是本卡唯一超出"补测试"范围的动作，请重点看。

**事实**：`benchmark_commands.py:76-79`（改动前）就是

```python
coordinator_release = bool(
    getattr(args, "coordinator_release", False)
    or getattr(args, "allow_model_execution", False)
)
```

而 real 分支用的是这个**已折算**的 `coordinator_release`。所以改动前，**只给 `--allow-model-execution`（无 `--test-substitute`）CLI 确实会选 `real_pipeline`**——T43 §0 里"CLI 的 real_pipeline 分支现在只认 coordinator_release，忽略 --allow-model-execution"这句描述与代码不符。

**后果**：T43 的 M-B（在 real 分支上加 `or allow_model_execution`）与原文**语义等价**，任何测试都不可能让它变红——它当时"没被抓到"不是套件弱，而是变异本身不可区分。要让卡面"3/3 变红"成立，只能把 CLI 选路收敛到**单一显式 flag**，我照此实现。

**语义变化与影响面**：

| 输入组合 | 改动前 worker_action | 改动后 worker_action |
|---|---|---|
| 无标志 | mock_run | mock_run（不变） |
| `--coordinator-release` | real_pipeline | real_pipeline（不变） |
| `--coordinator-release --allow-model-execution` | real_pipeline | real_pipeline（不变） |
| `--allow-model-execution` 单独 | **real_pipeline** | **mock_run**（收紧） |
| `--test-substitute`（± 其他） | mock_run | mock_run（不变） |

- 内层发布门（`execute_guarded` 的 `is_released`）**仍认 `--allow-model-execution`**，所以"能力"没被删；变的只是 CLI 在"只有 allow_model_execution"时的默认动作，且结果里 `worker_action` / `is_mock` 都可见；
- 现有测试无一条依赖"单给 `--allow-model-execution` 就真跑"，67 + 11 全绿。

**如果统筹认为"单给 `--allow-model-execution` 就该真跑"**，那 M-B 无法被任何测试抓到（等价变异），验收口径需要改成"2/3 变红 + M-B 记为等价变异"，并把我这处收紧回退。两种口径我都能落，但需要明确指令——本卡按卡面文字（"CLI 仅认 coordinator_release 选 real_pipeline" + "M-B 必红"）选了收紧。
