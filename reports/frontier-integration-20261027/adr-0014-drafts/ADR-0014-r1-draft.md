# ADR-0014 受限机制形成环（Constrained Mechanism Formation Loop, CMFL）

- 扩展 ID：**CMFL-r1-20261028**；日期：2026-10-28；状态：**proposed（草案，待 ainerzero.V9.A12 非作者审议）**。
- 起草：一级 claude-agy（Relay 卡 ainerzero.V9.A11）；设计来源：一级 claude 的 [REPORT](../../../AinerZero/reports/frontier-integration-20261027/REPORT.md) 与 [DESIGN_CORE](../../../AinerZero/reports/frontier-integration-20261027/DESIGN_CORE.md)（2026-10-27/28，原字节保留，不随本 ADR 修改）。
- 研究线主责统筹：claude（CMFL 线）。S1、T6、E0 等既有线主责不变。
- 用户授权口径：用户 2026-10-28「落地并入工作台」= 立项并登记卡片。**本 ADR 不授权**训练、MLX 运行、下载、安装第三方包（pysindy、PySR/Julia、MuJoCo 等）、付费、云 GPU，也不修改任何冻结参数、门槛、数据分区或已交付证据。
- 现行主基线：[V9-r5-20261016](../../../AinerZero/ARCHITECTURE_BASELINE.md) 与 [ARCHITECTURE_V9](../../../AinerZero/ARCHITECTURE_V9.md)；与 [ADR-0012](ADR-0012-v9-neurogeometry-hjepa.md)、[ADR-0013](ADR-0013-character-first-production.md) 兼容，不替换任何 accepted ADR。

## 0. 定位与一句话

CMFL 是 AinerZero **世界脑学习平面**的 S6/E1 扩展：在“学不学、学什么”之前，先用确定性层与参数辨识回答“现有机制够不够”；只有经过独立、可核验、单侧控制错误接受的检验，新机制才能从 MID 晋升到 SLOW。

- **不改** ADR-0013 角色优先主线：世界脑仍是旁路，不是出片前置，也不是 LLM 导演。
- **不建**第二套世界脑，不改 GeometryCore（零可学习参数），不改 AWZ 世界侧权威物理与 `mechanics_pack`；SLOW 机制库属于 AinerZero 学习侧，另立，不混进 AWZ 世界侧登记。
- 落点全部是 r5 已有接口：式 7（信息增益）、式 8（先验 φ̂ + 残差，机制 ID 与作用域）、式 6（学习保护）、式 13（配对 bootstrap 非劣/优越）、FAST/MID/SLOW、`SpatialMemory.consolidate/promote`、`PromotionEvidence`、`SkillProposal`、§2 Teacher Gateway、§7.2 教师=带噪传感器、§8.6 学习侧信息边界。

## 2. 决定

### D1 机制充分性门（Mechanism Sufficiency Gate, MSG）

**作用**：学习侧路由器，决定“怎么解释残差”。与 `UpdateScheduler`（决定“更新哪些信念节点”）正交，不替代它。

**输入边界（§8.6 硬约束）**：只读自身信念、允许观察、学生已执行动作，以及登记配置（D_permit、阈值登记）。绝不读 Event/v1、世界 ID、对象真值 ID、sim_truth、生成器偏差标签、评测通道。实现须在**实际加载路径**上测试，并通过 §8.6 的“同观察、异未来”反例：两个世界在 t 前观察相同时，MSG 在 t 的路由码与原因必须相同。

**路由**（对每个上下文 c = 信念子图 × 预测窗 W，按序判定，首条命中即停）：

| 序 | 路由码 | 判据 | 动作 |
|---|---|---|---|
| 1 | `ABSTAIN` | c 超出边界教师登记的 D_permit | 不探索，记原因；可请求扩大范围（新登记，不在运行内改） |
| 2 | `OUT_OF_DOMAIN` | 不存在 m ∈ SLOW 使 c ∈ D_valid(m)（越界由包络判定，见 D3-4） | 退回通用残差预测并放大不确定性；记为 MID 候选 |
| 3 | `NUMERICAL` | ε_num = ‖F_m(dt) − F_m(dt/2∘dt/2)‖ ≥ κ‖r‖ | 换积分器或步长，**不学习** |
| 4 | `SUFFICIENT` | NIS 统计量 Σ_{k∈W} r_kᵀS_k⁻¹r_k 落在 χ²(W·d) 的双侧 1−α_s 区间内 | 直接求解、缓存 |
| 5 | `PARAMETRIC` | 更新 p(φ\|D) 后，第 4 条在**未参与拟合的留出窗**上通过 | FAST 内在线辨识（参数增广滤波或低维 SMC，无网络） |
| 6 | `UNIDENTIFIABLE` | 在无量纲化参数上 λ_min(I_φ) < τ_id，或 H(p(m\|D)) > τ_H | 先做竞争机制筛查，只保留可区分可观测量；再在 D_permit 与预算内选探针（见 D4） |
| 7 | `STRUCTURAL` | 第 5 条后第 4 条仍在 ≥K 个**独立**上下文失败 | 开 MID 离线发现作业（D2） |

统计前提（实现与报告必须写明，不得省略）：

- 第 4 条的 χ² 分布只在“模型正确、残差为高斯、S_k 为正确的创新协方差、跨 k 条件独立”时成立（滤波创新满足；开环多步预测残差相关，必须改用联合协方差或降采样去相关）。
- 第 5 条若在拟合数据上复检，自由度应扣减拟合参数个数且不再是精确分布；故规定用留出窗。
- 第 6 条 I_φ = Σ J_kᵀS_k⁻¹J_k 是线性化高斯近似；λ_min 依赖参数尺度，τ_id 只对按先验尺度无量纲化后的 φ 有意义。
- 第 3 条先于学习：避免把积分误差学成假规律；第 5 条先于第 7 条：参数未辨识干净前不得宣称新结构。

**阈值冻结**：α_s、κ、τ_id、τ_H、K、W、积分器/步长集合、D_permit 版本写入一份 **MSG 登记文件**（带 SHA256），在运行（或实验）登记时冻结。运行内不得修改；改任何阈值 = 新登记 ID + 新实验 ID，旧结果不覆盖。阈值只能在留出标定集上用预登记规则确定（同 D3-8），不得在评测集上扫。

**可观测性**：每次判定记录路由码与原因，风格同现有 `fallback_reason()`，进入运行报告。

**评测（只在评测侧，封存，不进模型输入）**：生成器给出真实偏差类型（参数/结构/数值），算 MSG 混淆矩阵；模型恢复与参数恢复矩阵（报告不对称混淆）；改动定律世界（如 1/r 引力、各向异性惯性）检验非记忆；负对照：候选库故意缺项或缺状态时，晋升准入率应为 0。

### D2 离线发现（MID；不占实时帧率，CPU 优先）

1. 连续残差：自实现弱形式稀疏回归（STLSQ，NumPy）→ 可执行先验检查器剪枝（量纲一致、重力对齐 SE(2) 对称、无输入时能量不增、已知渐近）→ 仍不足才考虑重型符号搜索（PySR 等，**安装需用户另批**）。
2. 离散规则（门锁、局部禁区、开关）：受限 DSL + 反例引导归纳合成（CEGIS），在全部历史轨迹上回放逐例零回归。
3. LLM/教师提出的补丁只进 MID，与其他候选同等受检；关掉 LLM 时 1–2 仍可运行（r5 §2）。
4. 每个候选记 Pareto（误差 × 复杂度）、出处（proposer 类别、数据身份）与本作业尝试候选总数 N（供 D3-3）。
5. 网络残差只学确定性核心未覆盖部分：按覆盖度降权采样；分数层融合须带自适应缩放 γ = 1 + max log p − min log p。
6. 残差只读净化后的观测与动作，不碰引擎内部；规律切换用变点检测；对同一抽样反复修改过的候选，成功率估计偏乐观，故 D3 独立测试集不可省。
7. **残差与参数正交**：r_θ 约束在 ∂F_prior/∂φ 张成子空间的正交补内。后果须照写：此时 φ̂ 是 L² 投影参数，不是物理真值；真实偏差沿灵敏度方向的分量按定义并入 φ̂。
8. **选结构与做检验分开取数据**：data thinning 拆出独立视图（精确独立性只在已知方差高斯等可加性族成立；其余情形为近似，须写明），一份选项、一份检验；不可辨识项不报区间，视为弃权。
9. 失败轨迹只监督后果预测（下一状态、碰撞事件），不进入动作先验或技能模仿；10 步位置误差与碰撞 F1 在失败子集上单列。

### D3 单侧晋升门（MID → SLOW）

候选 m′ 对现任 m₀，在独立世界集合 T 上检验。发现数据 D、标定数据 C、测试集 T 三者身份强制不相交，全部取自 development 分区；**final 不碰**。“单侧”指只控制**错误接受**（把无效或更差的机制晋升）；误拒只报告，不作门。

1. **优越性**：按世界（或回合，取较粗的独立单元）配对 bootstrap，Δ = e(m′) − e(m₀) 的 95% 单侧上界 U < −δ_gain（式 13 的优越性镜像）；δ_gain 登记时冻结。
2. **旧能力保持**：式 6，原样适用。
3. **多重比较与序列控制**：
   - 单次作业：D 上只选一个候选，T 上只测一次；否则按登记的尝试数 N 做 α/N 校正。
   - 挑战者与 test_id 在看到决策证据前冻结。
   - 多世界族：每族一条随时有效 e-process，合成 E_pers = min_e E^e。这是交并检验（intersection-union）：要求在每一族都拒绝“不优于现任”；min 对每一族零假设都是有效 e 值，不需要跨族独立，但会被证据最慢的一族拖保守。
   - 整条晋升序列用在线 FDR（e-LOND：α_t = α·γ_t·(R_{t−1}+1)，Σγ_t ≤ 1，E ≥ 1/α_t 才采纳）；控制的是 FDR，不是 FWER。
   - 晋升会改变现任者，从而影响后续候选；路径依赖须写入报告。
   - 准入（ALDER 式）：文法、预算、准入阈值在发现前冻结；准入由提议方看不到的留出数据决定；预算内无人通过即不返回候选；失败提案不删，证据账本只追加。
4. **适用域 D_valid**：= (D ∪ C) 协变量覆盖包络 ∩ 标定残差分位数。
   - 共形覆盖只在可交换前提下、且只在 D_valid 内是**边际**覆盖；越界检测靠包络，不靠共形。
   - 先做可交换性自检（时间二分比较残差统计，必要时降采样去相关）。
   - 分位数用有限样本修正：取第 ⌈(1−α)(n+1)⌉ 个次序统计量；若 ⌈(1−α)(n+1)⌉ > n，证书为空，拒绝晋升。
   - 曲线残差可先 FPCA 降维再在系数空间做 split conformal。漂移下可用 ACI 在线更新，但只有长期平均覆盖，须报实测覆盖率，不得只引定理。
5. **反例与逐例不回归**：T 上失败上下文全部留档；带已知反例的晋升须先收窄 D_valid 再重测。回放门是**逐例**不回归，不是聚合分数改善。反例分类：执行/接口 > 缺失隐变量 > 状态/读出不符。
6. **审计统计**：先固定可复现与稳定过滤器再计违规；零失败时报精确二项上界 1 − 0.05^{1/n}；按世界族分别报小样本上界；曲线级与审计级分母分开。
7. **出处与独立性**：记录知识起源类别（sindy/symbolic/llm/teacher/human）；证据出具者必须是与生成过程隔离的独立测试身份，**不得是学生自身**（类别 self 不再可出具 SLOW 证据）；producer 由可信上下文绑定，不是自报字符串。判定是二值硬门，由独立仿真测试给出，不由任何评审模型给出。
8. **阈值标定**：接受阈值在留出集上用次序统计量标定；不得在评测集上扫阈值。
9. **回滚**：SLOW 条目版本化，带 supersede 指针；编码器、F_prior 或 GeometryCore 版本变化触发重验，重验完成前该条目不被确定性层使用（fail-closed）。

### D4 受限主动实验

- UNIDENTIFIABLE 分支选 a* = argmax EIG(a)，只在 D_permit 与登记预算内。线性高斯近似 EIG = ½ log det(I + S⁻¹JΣ_φJᵀ)；非高斯用嵌套 MC，须登记内外层样本数并说明其估计偏高（内层对数边际似然的 Jensen 偏差）。
- EIG 是学生自报量，**不进门禁**（同 SkillProposal 裁决 6）；执行仍经 SkillProposal 门禁与 AWZ 准入。
- 探针先只用 SkillProposal **v1 内已登记的探针能力**；若需携带假设引用、EIG、实验预算或干预白名单字段，须另行升版 v1.1（独立合同修订 + 非作者复核），本 ADR 不改 v1 schema（`additionalProperties:false` 原样）。

### D5 教师三职责

| 职责 | 落点 | 约束 |
|---|---|---|
| 知识教师 | φ 的先验、候选机制（带出处；§7.2 带噪传感器） | 永不直写 SLOW；只进先验或 MID |
| 边界教师 | 登记的 D_permit：可操作变量白名单、范围、安全边界、允许泛化包络 | 运行内冻结；是登记配置而非自由 LLM 输出；由 MSG 第 1 条与 SkillProposal 门禁共同执行 |
| 评估教师 | 反例与质疑，进入 MID 测试池 | 提出错误 ≠ 确认错误；判定只由独立仿真测试给出 |

工程先验（GeometryCore、F_prior）是版本化代码，按式 8 登记偏差来源，不走 SLOW 晋升；只有学到或发现的机制走 MID → SLOW。

### D6 E1 增补候选（S1 第二阶段预登记时再定；本 ADR 不授权训练）

现有四组 ①有偏先验 ②纯 MLX ③先验 + MLX 残差 ④真参数（上界诊断）**不改**；原门槛（③ 比 ①② 较好者好 ≥10%、碰撞 F1 不降）**不改**。候选增补臂只增加对照与诊断：

| 臂 | 内容 | 回答的问题 |
|---|---|---|
| ⑤ | 有偏先验 + 在线 φ 辨识（无网络，训练参数 0） | 参数类偏差是否根本不需要网络 |
| ⑥ | ⑤ + MLX 残差（辨识之后学，与 ∂F_prior/∂φ 正交）；另报有/无正交约束 | 网络在参数辨识之外的贡献 |
| ⑦ | ⑤ + 符号残差（弱形式稀疏回归，过 D3 才用） | 低算力规律提炼能否替代网络残差 |
| ⑧（可选） | ⑥ 的端口哈密顿约束版 | 能量漂移是否改善（只报告；须在实际离散积分器上实测，不得以连续时间存在性定理代替） |

两族世界：P 族（只有参数偏差，即现 E1）与 S 族（先验缺一项机制，按式 8 带机制 ID 与作用域）。假说：P 族 ⑤≈④ 且不劣于 ③；S 族 ⑥/⑦ 优于 ⑤。

前置（全部满足才可放出 P48 执行卡）：本 ADR 定稿；E0 真值修复 awz.V9.B20 通过且 B21 非作者复核通过；60 fps 对 120 Hz 对齐与 Z-up→重力坐标映射登记；S1 第一阶段过门；用户批准第二阶段训练预算；逐臂预登记数据、预算、种子、指标。

## 3. 契约变更清单、迁移与回滚

现状：`SpatialMemory` 只有 fake 实现，没有生产 SLOW 条目；因此迁移只涉及接口、fake 与合同测试。所有未入 git 的接口文件开工前先记 SHA（REPORT §2 治理问题）。

| 变更 | 内容 | 迁移 | 回滚 |
|---|---|---|---|
| C1 `PromotionEvidence` v2 | 新增：`schema_version`、适用域引用、校准（方法、α、n_cal、可交换性自检引用）、错误接受控制（在线 FDR 状态引用、尝试数 N、test_id 预登记引用）、反例引用、知识起源类别、发现/标定/测试数据身份（构造时强制不相交）、式 6 回归引用、条目摘要与编码器版本 | v1 对象仍可构造与读取，但 `promote` 只接受 v2；v1 证据一律拒绝晋升（fail-closed）并给明确错误 | v2 字段为纯增；回滚 = 恢复只认 v1 的 `promote`，不影响已有数据 |
| C2 producer 绑定 | 只读调用 `validation.validate_producer` 作为唯一登记表权威并在其上扩展；类别 `self` 不得出具 SLOW 证据；producer 由可信上下文绑定（照 teacher_cache 的 trusted_context / admission_bindings 做法），不再接受自报字符串 | 依赖 `producer="student"` 可晋升的测试须改写为负例；不另建第二套登记表 | 恢复原登记表映射即可 |

| C4 撤销与降级 | `SpatialMemory` 增 `revoke(item_id, reason, evidence_ref)` 与 `demote(item_id, to_level, reason)`；supersede 指针；版本变化触发重验 | 新方法，fake 与合同测试同步 | 新方法可整体移除，不影响 `promote` |
| C5 MSG 登记文件 | 新文件类型（阈值、D_permit 版本、积分器集合，带 SHA） | 新增，无旧数据 | 删除引用即可，不影响既有实验 |
| C6 SkillProposal | **本 ADR 不改**；探针用 v1 已登记能力；v1.1 另立 | — | — |

守卫类变更（C1–C4）的实现卡（ainerzero.V9.B12）必须附“拆守卫坏控”：逐条移除守卫后对应负例测试必须变红。

## 4. 明确不改

- r5 冻结基线、`baseline.v1.json` 原字节与冻结身份；E1 原四组与原门槛；S1 r13 冻结件（不往已冻结的 S1 加臂）；§8.6 信息边界；“教师与 LLM 不能写 SLOW”。
- ADR-0013 三系统职责与角色优先主线；AWZ 世界侧权威物理与确定性域。
- 训练暂停/解除口径（D-021）、预算、锁、RunStore、数据分区与 final 封存。

## 5. 后果与风险

- 正面：把“何时不该学/不该探索”变成可审计路由；晋升独立性从形同虚设变为可核验；E1 能区分“学到未知规律”与“只做参数推断”。
- 风险：MSG 阈值多，登记不当会变成调参自由度（以 D1 冻结规则约束）；合成玩具世界结论不得外推到 E0/Bullet，更不得外推到真实视频；新研究线与角色优先主线争夺统筹精力（世界脑仍为旁路，不成为出片前置）。
- 文献依据只作协议来源，不把任何论文数字当本机收益；条目最终采信以研究注册表 R11 补登记及其非作者复核（R12）为准。
