## 0. 为什么要这一版

第一阶段 dev1 有效，但留下三个没回答的问题，运行器也被打回。

| 问题 | 这一版的处理 |
|---|---|
| H2 输给手工线索（−0.052）：是学习检索不行，还是训练写法有问题 | 只改训练写法，门槛不动，重新检验 |
| H3 崩塌：读出头类别偏置和真实遗忘混在一起 | 用有界回放对付，门只对指定的臂生效，8 类读出单独判定干扰是否存在 |
| 运行器有 5 个必修项，区间不可复算 | 新运行器、新预登记、全新分区 `s3p2-*`，`s3p1-dev`、`s3p1-final` 不再使用 |

**这一版是验证性的，不是新发现。** 探针已经显示大致结果，价值是把结论放到干净分区上，配齐可复算的证据链。结论只由 final 下，dev 是彩排。

## 1. 探针结果

`s3p2-probe`，每族 100 世界 × 2 回合，3 个种子，用正式运行器。**只用来定设计，不作结论。** 表格由 `make_tables.py` 生成，完整版见 `TABLES.md`。主指标事件 2034 个，196 个回合。

| 臂 | F1 结束 |
|---|---|
| A0 无记忆 | 0.000 |
| O 真值检索 | 1.000 |
| N 打乱负对照 | 0.006 |
| A2 手工线索 | 0.856 |
| A3S 软混合 | 0.829 |
| A3H 硬采样 | 0.853 |

| 门 | 实测 Δ（95% 区间） | 判据 | 探针结果 |
|---|---|---|---|
| H2：A3H − A2 | −0.003（−0.028, +0.023） | ≥ 0.05 且下界 > 0 | 不过 |
| H2b：A3H − A3S | +0.024（+0.009, +0.039） | ≥ 0.03 且下界 > 0 | **不过** |
| H3′ 保留：A2-R64 的 F1 下降 | +0.015（+0.004, +0.026） | 上界 ≤ 0.05 | 过 |
| H3′ 可塑性：C0 − R64 的 F2 | +0.006（+0.001, +0.011） | 上界 ≤ 0.05 | 过 |
| 干扰存在（8 类） | +0.399（+0.373, +0.425） | ≥ 0.10 | 过 |
| 回放内容起作用（8 类） | +0.723（+0.692, +0.753） | ≥ 0.10 | 过 |

- **H2b 按探针不过，门槛不改。** 探索时软混合到硬采样 +0.065（0.789→0.854），新分区、2000 步、3 个种子上只有 +0.024（0.829→0.853）。「第一阶段输在训练写法」只得到部分支持：硬采样确实更好（下界 > 0），但幅度不到 0.03，并且第一阶段 A3 − A2 的差距 −0.052 在这里是 −0.027。
- **A2-CN 比不保护更差**（8 类读出 0.133，不保护 0.457）。错误的答案在主动教坏模型，所以这个门说明「回放内容重要」，不说明「打乱的回放等于没有回放」。
- 容量曲线：A2 的 R16 上界 0.058，R64 0.026，R256 0.021。A3H 对容量更敏感（R16 下降 0.329，R64 0.053，R256 −0.029），而且可塑性代价随容量上升（0.040、0.052、0.080）。
- **检索诊断：** 手工线索第一名严格命中 0.653，能看到答案 0.873；候选池 0.866、0.972。A2 的 0.856 接近自身上限 0.873；学习检索理论上还有约 0.10 的空间。
- **零状态对照（A2，种子 1）：** 有记忆减无记忆，短间隔 +0.031，中间隔 +0.146，长间隔 +0.474。
- **更正：** DEV1-REPORT §3 猜「A3 还没收敛」不成立，探索中软混合训到 8000 步也不涨（`TABLES.md`）。

## 2. 假设

世界、观察、巡游、情景库、候选池、读出结构都沿用第一阶段，源码不改。步数同第一阶段。

| 假设 | 判据 | 判定时点 | 备注 |
|---|---|---|---|
| **H1（基础门）** | A2 − A1 ≥ 0.10，配对区间下界 > 0 | F1 结束 | 由结构决定，不作发现宣称 |
| **H2（检索）** | A3H − A2 ≥ 0.05，配对区间下界 > 0 | F1 结束 | 门槛不动。看过第一阶段结果后的第二次检验，预期不过 |
| **H2b（诊断）** | A3H − A3S ≥ 0.03，配对区间下界 > 0 | F1 结束 | 检验「输在训练写法」。与 H2 的区间一起解读，H2b 过也不代表 A3H 不差于 A2 |
| **H3′（保护，式 6）** | A2-R{选定容量} 的 F1 下降上界 ≤ 0.05，且 A2-C0 的 F2 减该条件 F2 的上界 ≤ 0.05 | F2 结束 | 门槛沿用 0.05，改成上界更严。保护和可塑性同时满足。A0 这类平凡情形不进门 |

## 3. 臂

| 臂 | 记忆 | F2 阶段 | 用途 |
|---|---|---|---|
| A0 | 无 | 无 | 合法性：地板 |
| O | 真值检索 | 无 | 合法性：上界 |
| N | 随机一条过去记录 | 无 | 合法性：负对照 |
| A1 | GRU | 无 | H1。只在 dev、final、smoke 中，探针不含 |
| A3S | 学习检索，软混合 | 无 | H2b，复现第一阶段写法 |
| A2-C0 | 手工线索 | 只训 F2 | H3′ 对照，验证干扰 |
| A2-R16、R64、R256 | 手工线索 | F2 加回放 | 选定容量进 H3′，其余只描述 |
| A2-CN | 手工线索 | 回放 64，答案打乱 | 负对照 |
| A2-J | 手工线索 | 联合训练 | 上界参考 |
| A3H-C0、R16、R64、R256、J | 学习检索，硬采样 | 同 A2 | H2、容量曲线，只描述 |

- **硬采样（A3H）：** 训练时按打分的 masked softmax 采样一条候选，读出头只看这一条。打分头目标不变，`util = −CE(带这条记录)`；原式里的无记忆 CE 对同一事件的所有候选相同，softmax 后被消去，两种写法等价（测试 `test_scorer_target_matches_the_frozen_utility`）。评测沿用冻结的 `arms_mlx.forward(hard=True)`，取最高分一条。随机键：`mx.random.key(seed)`，每步 `split`。
- **回放：** 对每个种子，用 `7_000_000 + seed` 打乱 F1 训练回合，取前 n 个作缓冲，不放回。同一排列，所以 R16 ⊂ R64 ⊂ R256。F2 每步 16 个回合：8 个来自 F2、8 个来自缓冲，各自不放回抽取。优化器状态延续。
- **选定容量：** 探针上 16、64、256 中，保留和可塑性两个上界都 ≤ 0.05 的最小容量。这个规则定在看到探针结果之前，结果是 **64**。R64 也是 r0 看过探索后选的，这里写明；规则和探针都没有用 dev、final。
- **A2-CN：** 用与 R64 相同的 64 个回合，把缓冲内所有事件的答案跨回合随机置换（种子 `7_100_000 + seed`）。`swapped`、`bucket`、观察和检索都不变。答案的类别分布不变，破坏的只是「记录—答案」的对应关系。
- **N：** 每个事件在 `[0, t−5]` 上均匀抽一条记录（种子 `7_200_000 + perm_seed`），由 `replay.past_only_shuffle` 替换冻结 `batching.py` 里的字段。
- **联合训练（J）：** F1 + F2 的总步数，每步 8 个 F1 回合加 8 个 F2 回合。
- **步数：** F1 2000，F2 1000，同第一阶段。

## 4. 指标与门

**主指标：** 长间隔（≥ 80 步）且 token 已换事件的准确率，16 类全开读出。按回合配对 bootstrap，10000 次，种子 20261109，三个种子的事件合并，同一回合一起进出。

H1、H2、H2b 在 F1 结束时读。下降量在同一分区、同一批事件上算，F2 前后配对。

| 合法性门 | 判据 | 失败的后果 |
|---|---|---|
| 地板 | A0 ≤ 1/7 + 0.03 | 整个实验无效 |
| 上界 | O ≥ 0.90 | 整个实验无效 |
| 负对照 | N ≤ 1/7 + 0.03 | 整个实验无效 |
| 未换事件 | A2-C0、A3H-C0 在 F1 结束时 ≥ 0.80 | 整个实验无效 |
| 确定性 | 两组条件的 F1 阶段逐事件预测完全相同 | 整个实验无效 |
| 最小样本 | 每个种子主指标事件 ≥ 200、回合 ≥ 50（F1、F2 分别） | 整个实验无效 |
| 干扰确实存在 | A2-C0 的 F1 下降（8 类读出）≥ 0.10 | 只作废 H3′ |
| 回放内容起作用 | A2-CN 的 F1 下降（8 类读出）≥ 0.10 | 只作废 H3′ |

**常设报告（缺项判运行不完整）：** 分桶曲线；8 类受限读出；平衡准确率；在被评测分区上算的 precision@1、候选池严格召回率和「能看到答案」比例；零状态对照；每格训练耗时；峰值内存。

## 5. 分区与用量

全新命名空间 `s3p2-train`、`s3p2-dev`、`s3p2-final`、`s3p2-probe`，与 `s3p1-*` 的世界种子不相交（测试 `test_new_namespaces_are_disjoint_from_phase_one`）。规模同第一阶段：train 400 世界 × 4 回合，dev 50 × 2，final 100 × 2，probe 100 × 2，两个世界族各一份。种子 1、2、3。

dev 至多两次，账本写用途。final 冻结后才生成，只读一次，批准行写进预登记。**只有 final 能支持结论。** dev 上的门照算，用来彩排；除非合法性门失败或运行器出错，否则不因 dev 结果改设计。

## 9. 这一版不回答

- 跨回合记忆、FAST→MID→SLOW 晋升与回滚、容量受限的情景库、Titans 式记忆。这些才是下一步的新问题，等这版收口后单独设计。
- 式 6 这里只作训练后的保留门，不做逐步晋升判定。
- 回放用了 F1 的真实答案标签。在这个任务里答案是智能体当时看到的 token，但不外推到无标签场景。
- 结果只针对 GridLab-S3 这个读回任务，不外推到规划。
- 参数锚定没有纳入：探索中 λ=1、10 都让 F2 学不动，选强度本身需要一轮调参。

## 10. 风险

- **H3′ 和 H1 接近由结构决定。** 回放挡住浅层网络的遗忘是已知现象，通过不算发现。
- **探针和登记共用世界生成器与超参。** 探针只用 `s3p2-probe`，dev、final 是新种子。
- **复核者与作者同模型。** 第二路复核是独立会话，但模型层面的盲点可能相关。
