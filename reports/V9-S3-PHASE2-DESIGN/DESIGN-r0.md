## 1. 探索结果（一级，未登记）

只用 `s3p1-train` 训练、`s3p1-probe` 评测，2 个种子。**只用来定设计，不作结论。** 全部数字是长间隔且 token 已换的事件。

**候选的天花板（纯数据，不训练，400 回合，1353 个事件）**

| 口径 | 真值记录 | 手工线索第一名 | 候选池任一条 |
|---|---|---|---|
| 记录的视野里能看到答案 | 1.000 | 0.860 | 0.958 |
| 答案就在记录的中心格 | 1.000 | 0.714 | 0.888 |

A2 训练后约 0.85，已经贴着自己的上限 0.860，这是它高于严格命中率的实测解释。学习检索理论上限 0.958，比手工线索高约 0.10，所以 H2 的 +0.05 不是做不到的。

**学习检索：多少步、怎么训**

| 臂 | 1000 步 | 2000 | 4000 | 8000 |
|---|---|---|---|---|
| A2 手工线索 | 0.846 | 0.841 | 0.837 | 0.827 |
| A3 软混合（第一阶段写法） | 0.785 | 0.789 | 0.790 | 0.762 |
| A3 硬采样（读出头每次只看一条） | 0.845 | 0.854 | 0.856 | 0.854 |

- **更正：** DEV1-REPORT §3 猜测「2000 步时 A3 还没收敛」，这个猜测不成立，软混合训到 8000 步也没有变好。
- 第一阶段 A3 输的主要原因是训练看软加权混合、评测看单条。修正后约 +0.065，与 A2 大致持平（+0.01），仍未达到 +0.05。

一律沿用第一阶段的世界、观察、巡游策略、情景库、候选池和读出结构，源码不改。

| 假设 | 判据 | 备注 |
|---|---|---|
| **H1（基础门）** | A2 − A1 ≥ 0.10，配对区间下界 > 0 | 同第一阶段，几乎由结构决定，不作发现宣称 |
| **H2（检索）** | A3H − A2 ≥ 0.05，配对区间下界 > 0 | 门槛不动。探索约 +0.01，预期不过 |
| **H2b（诊断）** | A3H − A3S ≥ 0.03，配对区间下界 > 0 | 检验「第一阶段输在训练写法」这个解释 |
| **H3′（保护，式 6）** | A2-R64 的 F1 下降 ≤ 0.05，且 A2-C0 的 F2 减 A2-R64 的 F2 ≤ 0.05 | 门槛沿用 0.05；保护和可塑性必须同时满足 |

H2 在第一阶段 dev 上已经未通过，这里是看过结果后的第二次检验，报告里要写明。H3′ 只对 A2-R64 判定，A0 这类平凡情形不进门。

## 3. 臂

| 臂 | 记忆 | F2 阶段 | 用途 |
|---|---|---|---|
| A0 | 无 | 无 | 合法性：地板 |
| O | 真值检索 | 无 | 合法性：上界 |
| N | 打乱记录，只在 `t−5` 之前打乱 | 无 | 合法性：负对照 |
| A1 | GRU | 无 | H1，只训 F1 |
| A2-C0 | 手工线索 | 只训 F2 | H3′ 对照，且验证确有干扰 |
| A2-R16 / R64 / R256 | 手工线索 | F2 加回放 | R64 是 H3′；其余是容量曲线，只描述 |
| A2-CN | 手工线索 | 回放 64，答案在缓冲内打乱 | 负对照：保护必须来自回放内容 |
| A2-J | 手工线索 | 联合训练 | 上界参考 |
| A3S | 学习检索，软混合 | 无 | H2b，复现第一阶段写法 |
| A3H-C0 / R64 / R256 / J | 学习检索，硬采样 | 同 A2 | H2、容量曲线，只描述 |

- **硬采样：** 训练时按打分的 softmax 采样一条候选，读出头只看这一条。打分头目标不变：`util = −CE(带这条记录)`。复核已证实原式里的 `ce_0` 对同一事件所有候选相同，softmax 后被消去，两种写法等价。评测仍是取最高分一条。
- **回放：** F1 结束时从 F1 训练回合均匀抽取 n 个回合，种子固定。F2 每步一批 16 回合：8 个来自 F2、8 个来自缓冲。缓冲只存整回合，单位是回合数，不是事件数。
- **步数：** F1 3000，F2 1500，各臂相同。O、N、A0 只训 F1。
- **N 的修正：** 第二路复核发现打乱范围是全回合，25/67 个事件读到未来记录。改为只在 `t−5` 之前打乱。

## 4. 指标与门

**主指标：** 长间隔（≥ 80 步）且 token 已换事件的准确率，16 类全开读出。按回合配对 bootstrap，10000 次。

下降量在同一分区、同一批事件上计算，换族前后配对，三个种子取平均。

| 门 | 判据 |
|---|---|
| 地板 | A0 ≤ 1/7 + 0.03 |
| 上界 | O ≥ 0.90 |
| 负对照 | N ≤ 1/7 + 0.03 |
| 未换事件 | A2、A3H 的 F1 ≥ 0.80 |
| 干扰确实存在 | A2-C0 的 F1 下降 ≥ 0.20 |
| 回放内容起作用 | A2-CN 的 F1 下降 ≥ 0.20 |
| 确定性 | 同种子各条件的 F1 阶段逐事件结果完全相同 |
| 最小样本 | 主指标事件 ≥ 200，回合 ≥ 50，否则判失败 |

合法性门任一不过，整个实验判无效。

**常设报告（这次必须出，缺项判运行不完整）：** 按间隔分桶曲线；8 类受限读出；平衡准确率；手工线索的严格 precision@1、候选池严格召回率和「可见答案」比例（在被评测分区上算）；M2 干扰诊断（`memory_interference`，用 F2 前后的分桶准确率作 `before`、`after`，零状态读出作 `zero_state`）；每格训练耗时；峰值内存。

## 7. 预算

本机 MLX CPU，不付费。按探索实测估算：数据生成约 4 分钟；每个种子除 A1 外约 4 分钟；A1 每种子约 10 分钟。一次 dev 或 final 约 45 分钟，硬上限 1.5 小时。探针加 smoke ≤ 20 分钟。全部合计 ≤ 4 小时。

## 10. 风险

- **H3′ 和 H1 都接近由结构决定。** 回放挡住浅层网络的遗忘是已知现象，通过不算发现。
- **探索与登记共用同一套世界生成器和超参。** 探索只用了 train 和 probe，dev、final 都是新种子。
- **复核者与作者同模型。** 第二路复核用的是独立会话，有模型层面的盲点相关。gemini 可以复核，但一级要对证据逐条抽查。
