### 3.3 9.1 增补：`BlenderWorld`（评测基准，非世界模型）
- **定位**：3D 创作智能体**评测基准（evaluation benchmark），非世界模型（`is_world_model: false`）**。
- **官方链接**：仓库 https://github.com/QwenLM/BlenderWorld ；HuggingFace 数据集卡 https://huggingface.co/datasets/Qwen/BlenderWorld ；技术报告 PDF 位于仓库 `docs/` 下。
- **任务规模**：**223 任务**（`bw_0001`–`bw_0223`，9 大类 22 子类）、**2,651 加权二元判据**（权重 1/2/3）；按输入模态：**纯文 78 / 图文 130 / 视频文 15**（另 59 个任务带规格附件）。
- **计分方式**：`Final score = 0.5 × rubric score + 0.5 × dimension score`（**50% 加权二元判据 + 50% 八维整体视觉质量**；Cycles `1024×1024` 64 samples 渲染 8 个自适应视角，每视角最多 2 次修正重渲染；缺失或失败提交计 0 分并保留在分母中）。
- **官方评测环境要求**：**Linux**（Harbor 0.23.0 需 GPU Linux 沙盒）、**Blender 4.2.10**、Node.js 22.17.0、`ffmpeg`/`ffprobe`、**Claude Code CLI 2.1.220**（捆绑生成环境含 Codex CLI 0.147.0）、**付费 VLM 接口**（`BW_AGENT_JUDGE_ENDPOINT` / `BW_VISION_JUDGE_ENDPOINT`，论文使用 `GPT-5.6-terra`）。
- **许可证核实**：代码仓库为 **MIT**（GitHub API `license.key="mit"`）；HuggingFace 数据集卡为 **MIT**（`https://huggingface.co/api/datasets/Qwen/BlenderWorld` 返回 `cardData.license="mit"` 且 README YAML 头明写 `license: mit`）。
