## 1. 门是否可检验（DESIGN-r1 §5）

### 1.1 成功率差 ≥ 10pp + 配对 bootstrap 下界 > 0 的功效

**结论：有问题（回合数未定，按合理假设功效常不足）。** 引用 §5「H-S2 过门」。

估算（正态近似，非精确 bootstrap；**假设写明**）：

| 假设 | 取值 |
|---|---|
| 配对回合数 | n（设计稿未给，试算） |
| 真成功率 | p_C = p_base + 0.10，对照 max(A,B) = p_base |
| 配对相关 | corr(I_C, I_base) = 0.4（同回合同起点，中等相关） |
| 判据近似 | 配对差均值的正态 95% 双侧 CI 下界 > 0（≈ 要求 ẑ − 1.96·SE > 0） |
| p_base 试算 | 0.20 / 0.30 / 0.40 / 0.50 |

SE(Δ) ≈ √[(v_C + v_base − 2·corr·√(v_C v_base))/n]，v=p(1−p)。真 Δ=0.10 时，近似功效 P(CI 下界>0)：

| n | p_base=0.2 | 0.3 | 0.4 | 0.5 |
|---|---|---|---|---|
| 50 | ~0.32 | ~0.27 | ~0.26 | ~0.26 |
| 100 | ~0.56 | ~0.49 | ~0.45 | ~0.45 |
| 200 | ~0.85 | ~0.78 | ~0.74 | ~0.74 |
| 300 | ~0.96 | ~0.92 | ~0.89 | ~0.89 |

**判断：** 若 final/dev 各只有几十～百余回合，门几乎不可靠（功效远低于常规 0.8）。要支撑「10pp 且 CI 下界>0」，在上述假设下大致需要 **n ≳ 200–300 配对回合/臂对比**（再乘种子聚合方式）。设计稿 §5–§6 未冻结 n，也未说明按种子宏平均还是回合池化——**门目前不可检验到可执行精度**。

若真实效应只有 5–8pp，或 corr 更低、基线接近 0.5，所需 n 更大。smoke 后若基线成功率极低（房间混淆导致全臂≈0），功效公式失效，门无意义。

## 2. 计算量对齐能否核实（§4）

**结论：有问题（意图清楚，计数与防作弊未钉死）。**

- **怎么计 N_fwd：** 稿只说「模型前向调用数」「按实测计数核对 ±5%」。未定义一次前向 =（a）整段 CEM 候选的 predictor 一步，还是（b）含编码器，还是（c）RSSM 的 imagine 一步。分层臂另有 E₂(ẑ¹) 与上层宏动作预测，若不计入会系统性偏袒 C/D。
- **防作弊：** 上层把算力藏进「编码/缓存/批外预处理」时，若只数 predictor 调用会漏计。需规定：每次决策从收到观察/目标到选出动作，**所有** `encode` / `predict` / `E₂` / IDM（若调用）计入同一计数器；禁止在计数外预计算大批候选嵌入；允许的 KV/状态缓存须登记且两臂对称（flat 也应能缓存当前 z）。
- **同一单位：** flat 在原始动作序列上滚动，分层上层宏动作 + 下层 s₂ 原始动作。若「一次前向」=「predictor 对一个 (z,a,dt) 推进一步」，则单位可对齐；若 flat 一次评估整条 H 步轨迹只算 1、分层逐步算，则不对齐。稿未选定义 → **无法判断当前写法是否同单位，缺显式定义**。

### extra_focus_r1

1. **房间相似混淆：** 故意保留混淆（§2）。足以让 flat 吃亏是假说本身；也足以让**所有臂学不会**。§5 SLIM 式动作敏感性预检部分覆盖「不可规划」，但**不覆盖「可规划却因歧义房间无法跨房」**。需在 smoke 报告各臂长目标成功率下界；若全臂≈0，停并改布局（加房间纹理/landmark），不要硬训满预算。
2. **目标观察歧义：** 目标 = 某格+朝向的 7×7 视野，**不给坐标**。相似空房间内多格可产生相同或近邻观察 → 成功判定若只比「是否匹配目标观察」会有歧义；若成功用**评测侧真值位姿**而学生只看观察，则「到达观察等价的错误房间」算失败——门可算清，但任务更难，且 planner 目标编码可能对应多模态位姿。**成立风险：有问题。** 数据生成应断言/报告目标观察哈希碰撞率；碰撞超阈值则加不可见 landmark 或扩大差异，或目标改为「观察 + 短方位提示」并预登记。
3. **带噪 BFS 泄露：** 训练轨迹以最短路为主、仅 0.2 随机扰动，长时域拓扑大量进入序列。flat 与分层**同学**这些轨迹；规划时 flat CEM 若主要复述训练集动作模式，可在不算「学到分层抽象」的情况下抬高成功率。**有问题（威胁内部效度）。** 应混入更高熵探索（随机游走/Frontier）并设最低比例；评测强调需重规划的扰动起点；报告「近 BFS 模仿」基线。

## 7. 遗漏（会使结论不可信的因素）

1. **目标观察多对一**（上节）——高优先。
2. **探针过拟合：** §5 用冻结潜状态上线性/小 MLP 读位置作非劣门；若探针在同一 dev 上选结构/早停，会偏袒表示更「探针友好」的臂。应固定探针架构与训练步，只用 train 子集拟合，dev/final 一次评估。
3. **参数量 ±20%（§3/§7）偏宽：** 2M 的 20% 是 0.4M，可改变容量档；建议收窄到 ±10% 或按 FLOPs/宽度登记，并报告实际参数表。
4. **成功定义未写清：** 到达目标格+朝向？容差？是否允许过冲后停在观察等价格？
5. **H 与 s₂、回合上限、N_fwd、n_episodes 均未数值冻结**——门与预算无法闭合。
6. **不规则 dt + 宏动作 s₂=8：** 上层「8 步」是环境步还是墙钟？Δt₂ 已按时长和，但 CEM 宏动作离散化是否含 k 重复，未写。
7. **M2「不可比仍照报」：** §7 正确；若数值碰巧接近，仍可能被误读——报告模板应强制「不可比」字段。

### 必改项

1. **冻结配对回合数 n（及种子聚合方式）**，附功效假设；不足则降门（如只报区间、不宣称 10pp 硬门）或加回合。
2. **写明 δ_pred 事前规程与单位**，禁止看分层对比后再改。
3. **定义 N_fwd 原子单位**（建议：决策期内每一次 encode/predict/E₂ 调用），分层与 flat 同一计数器 + 禁止计数外预计算；±5% 按此核。
4. **目标观察唯一性检查**（碰撞率阈值）+ 成功判定绑定评测侧位姿；学生侧仍可不给坐标。
5. **训练数据提高非 BFS 探索比例**（登记最低份额），并增加扰动重规划评测，抑制路径泄露抬高 flat。
6. **E₂ 合谋诊断**（动作敏感性或打乱子目标负对照）列入 smoke/必要条件。
7. **探针协议防过拟合**（固定架构、train-only 拟合）。

### 非阻断但建议

- 参数量容差收窄；写清成功容差与 H/s₂/N_fwd 数值；smoke 全臂长目标成功率熔断。
