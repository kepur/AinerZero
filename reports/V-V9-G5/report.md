## 4. 三项修复逐条核实结论

### 4.1 F1：半正定容差与位姿图负特征值截断
- **机制核查**：`belief.covariance(..., semidefinite=True)` 采用相对谱容差 `tol = PSD_RELATIVE_TOL * max(1, ||M||_2)`，其中 `PSD_RELATIVE_TOL = 1e-12`。先对称化后做特征值分解，判定 `min(eig) >= -tol`。严格正定路径维持 `smallest <= 0`。
- **尺度不变性**：在 scale 从 1e-6 到 1e6 的范围内，相对容差比例保持恒定，成功解决原 G1 在浮点舍入下误拒精确整数 PSD 矩阵的问题，且坚决不放过真负定矩阵。
- **下游位姿图**：`pose_graph.py` 在计算信息矩阵平方根前，显式将 `[-tol, 0)` 范围内的微小负舍入特征值截断为 0，防止开方产生 NaN。同时保留严格的可观测性检验，缺锚与断图依然稳固 fail-closed。
- **核实结论**：**修复严密、数值正确、边界完整**。

### 4.2 F2：重力参考相对方向判定
- **机制核查**：`GravityFrame` 去除了原绝对范数 `norm(x) < 1e-12` 判定，改用归一化方向判定 `sin_theta = norm(x) / norm(h) < 1e-9`。
- **尺度不变性**：同一方向在 1e-13 到 1e13 跨 26 个数量级下，判定结果与生成的正交基底完全一致。
- **异常清晰性**：错误提示精确反映当前判据 `(|sin theta| < 1e-9)`，且先行拦截零向量与非有限值。
- **核实结论**：**修复严密、尺度不变、满足物理约束**。
