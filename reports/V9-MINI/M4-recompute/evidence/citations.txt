## 1. 要检验的主张

**判定方法：** 每条门都看同一回合配对的成功率差（长目标子集），区间是按图整簇重抽样的 95% bootstrap 区间。

- 簇是「训练种子 × 留出图」：5 个种子各用一套互不重叠的留出图，所以簇就是各张不同的图。
- 点估计取所有入选回合差值的平均。
- 重抽样 4000 次，随机种子 0。
- 实现：`ainerzero.v9.mini.summarize.cluster_ci`。

**为什么按图、不按回合：** 同一张留出图上的回合共用探索前缀和起点，彼此不独立。探索批次 3 里，hybrid_self 和 hybrid 之间的差别全部来自一张图上的 4 个长目标。按回合重抽样时区间不含 0，按图重抽样时区间是 [−0.176, 0]。r0 的门槛是按回合区间定的，这次一并重定。

| 编号 | 主张 | 世界 | 门（全部是长目标成功率） | 探索批次 3 的值（3 个种子共用 30 张图，按图算区间） |
|---|---|---|---|---|
| H1 | 规划代价要接在显式地图上：度量地图规划胜过最好的潜空间规划 | m1、m2 各判一次 | map_hybrid 减最好的潜空间组 ≥ 0.50，且下界 > 0。最好的潜空间组在 latent_euclid、latent_learned、graph_memory、gru_belief 里按确认段结果事后取最大，对潜空间有利 | m1：1.000 对 0；m2：0.843 对 0 |
| H2 | 解析先验加门控学习残差，在有未知规律时胜过只用解析先验 | m2 | hybrid − analytic ≥ +0.10，且下界 > 0 | 批次 3：+0.240 [+0.064, +0.471]（17 张图）；scale80：+0.171 [+0.075, +0.283]（47 张图） |
| H2′ | 规律全部已知时不变差（非劣） | m1 | hybrid − analytic 的下界 ≥ −0.02 | 0 [0, 0]（10 张图） |
| H3 | 学到跨图通用的规律，胜过只记本图事件 | m2 | hybrid − memory ≥ +0.05，且下界 > 0 | 批次 3：+0.240 [+0.059, +0.427]；scale80：+0.112 [+0.027, +0.212] |
| H4 | 不用真值标签，自监督也能学到有用的规律（M3） | m2 | 两条都要满足：① hybrid_self − analytic ≥ +0.08，且下界 > 0；② 前进模型在留出数据上的事件准确率，真值标签版本减自监督版本，5 个种子平均 ≤ 0.05 | ① 批次 3：+0.181 [+0.010, +0.363]；scale80：+0.171 [+0.075, +0.282]；② 批次 3：0.992/0.993/0.980 对 0.968/0.985/0.959，差约 0.02 |

**H4 为什么改写。** r0 的 H4 是「hybrid_self − hybrid 的下界 ≥ −0.03」。这个门槛是按回合区间、用修复前「两者完全相同」的数字定的。修复后，批次 3 里 hybrid_self 比 hybrid 少 0.059，全部来自一张图；按图算的区间是 [−0.176, 0]。在这种波动下，−0.03 的非劣界限不是一个预期能通过的检验。

r1 把 H4 改成主张本身能检验的形式：去掉真值标签后，学到的规律仍然明显胜过不学习的规则。hybrid_self 与 hybrid 的差改为只报告、不设门，并在结论里写明。

**只报告、不设门：**
- hybrid_self − hybrid 及其区间；
- ungated、ungated_aug 两组：它们混着「学到的规律」和「先验对未知格乐观」两个因素，见 PLAN §7.3 第 3 条；m1 上它们的 SPL 反而更高（0.999 对 0.934），也是这个原因；
- 一步和 5 步误差比、代价秩相关、GRU 信念的秩相关；
- 惊讶率、迷路次数（新记录的 `prefix_lost`、`lost_at_start`）、SPL、短目标、规律相关回合的子集。

**结论怎么写：**
- 每条门单独报「过 / 不过」；不过的照实写，不改门、不换指标、不加种子。
- 全部过了，也只说「这几条主张在这个小世界里得到确认性支持」，不说「架构被证明正确」。

## 4. 结论（按预登记的写法）

H1、H2、H2′、H3、H4 这几条主张在 GridMini 这个小世界里得到确认性支持，**待非作者复算**。这不等于「架构被证明正确」。

**限定：**
1. **世界很小。** 3 个房间、5×5，视野半径 2；未知规律只有冰带和单向传送门两种。
2. **H1 比的潜空间组是本项目自己实现的小模型。**
   - 它们在两个世界的长目标上都几乎是 0，所以 H1 的差值很大。
   - H1 只说明「在这个世界里，这几种潜空间规划不如显式地图」，不代表它胜过更强的潜空间世界模型。
3. **真值依赖。** H4 只去掉了「前进模型的训练标签来自真值位姿」这一项。几何先验、格子类型折叠等仍是手写的，见 PLAN §6.3。

def cluster_ci(d, d2, keys, rng, n_boot: int = 4000):
    """按簇（图）重抽样的 95% 区间：每次抽同样多的簇（有放回），估计量是抽中簇的回合差值之和除以回合数。"""
    if any(k[1] is None for k in keys):
        raise ValueError("回合缺 layout_seed，不能按图重抽样（旧版 episodes.json）")
    uniq = sorted(set(keys))
    idx = {k: i for i, k in enumerate(uniq)}
    g = np.array([idx[k] for k in keys])
    s1 = np.bincount(g, weights=d, minlength=len(uniq))
    s2 = np.bincount(g, weights=d2, minlength=len(uniq))
    c = np.bincount(g, minlength=len(uniq)).astype(float)
    b = rng.integers(0, len(uniq), (n_boot, len(uniq)))
    lo, hi = np.percentile(s1[b].sum(1) / c[b].sum(1), [2.5, 97.5])
    lo2, hi2 = np.percentile(s2[b].sum(1) / c[b].sum(1), [2.5, 97.5])
    return lo, hi, lo2, hi2, len(uniq)
