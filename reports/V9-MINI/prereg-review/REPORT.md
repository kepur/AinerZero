### 必查项 2：`cluster_ci` 的代码实现审计
- **定位**：`src/ainerzero/v9/mini/summarize.py:29-44`
- **代码结构剖析**：
  ```python
  def cluster_ci(d, d2, keys, rng, n_boot: int = 4000):
      if any(k[1] is None for k in keys):
          raise ValueError("回合缺 layout_seed，不能按图重抽样（旧版 episodes.json）")
      uniq = sorted(set(keys))
      idx = {k: i for i, k in enumerate(uniq)}
      g = np.array([idx[k] for k in keys])
      s1 = np.bincount(g, weights=d, minlength=len(uniq))
      s2 = np.bincount(g, weights=d2, minlength=len(uniq))
      c = np.bincount(g, minlength=len(uniq)).astype(float)
      b = rng.integers(0, len(uniq), (n_boot, len(uniq)))
      lo, hi = np.percentile(s1[b].sum(1) / c[b].sum(1), [2.5, 97.5])
      lo2, hi2 = np.percentile(s2[b].sum(1) / c[b].sum(1), [2.5, 97.5])
      return lo, hi, lo2, hi2, len(uniq)
  ```
1. **簇的定义与键构造**：
   - 当 `same = True`（回合集相同）时，第 103 行 `keys = per_run[0][2]`，元素为 `(0, ra.get("layout_seed"))`，簇为地图（`layout_seed`）；
   - 当 `same = False`（回合集不同）时，第 97 行 `[(0 if same else ri, ra.get("layout_seed")) ...]`，簇键明确为 `(ri, layout_seed)`，**明确包含了运行编号 `ri`**，簇即为「运行 × 图」。
2. **估计量形式**：
   - 采用标准比率估计量（Ratio Estimator）：`s1[b].sum(1) / c[b].sum(1)`（抽中簇的指标和除以抽中簇的回合数）。这在各图所包含的回合数不完全一致（由于最短路长度不同导致长目标数量波动）时，数学上保证了估计量的一致性。
3. **缺失 `layout_seed` 防御性检查**：
   - 第 31 行 `if any(k[1] is None for k in keys): raise ValueError(...)` 能够对缺失 `layout_seed` 的旧版数据立刻抛出异常，绝不静默降级为按回合算。
4. **小例子测试验证**：
   - 构造微型极端数据集：簇 A 包含 4 个回合，差值均为 `-1.0`；簇 B 包含 4 个回合，差值均为 `0.0`。
   - 实测结果：
     - 按簇重抽样 95% 区间：`[-1.00, 0.00]`（取值严格为 `{-1.0, -0.5, 0.0}`，正确覆盖 0）；
     - 按回合重抽样 95% 区间：`[-0.88, -0.12]`（错误排除 0）。

### 必查项 4：预登记 r1 的门限与统计设计审定
1. **每条门是否可判、无歧义**：
   - **点估计与下界**：预登记明确规定统一考察长目标子集（`kind == 'long'`）的同一回合配对差，点估计为全样本回合均值，区间为按图整簇 4000 次 bootstrap 的 2.5% 与 97.5% 分位数。
   - **H1 潜空间组事后取最大**：明确限定在 `latent_euclid`、`latent_learned`、`graph_memory`、`gru_belief` 4 组中事后取最大，有利于潜空间对照，门限 $\ge 0.50$ 且下界 $> 0$ 无歧义。
   - **H2、H2′、H3、H4**：判定世界、对照组、门限数值、下界条件均清晰封闭。
2. **H4 改写（自监督仍胜过解析先验）的性质判断**：
   - **判断**：**这是科学合理的冻结前预登记修正，绝非事后放宽数据。**
   - **理由**：
     1. M4 仍处于预登记草稿阶段（未进入确认段 8_000_000 起的数据运行），探索段的职责正是暴露度量方差并校准检验主张；
     2. 原 r0 的非劣门（`>= -0.03`）是基于旧代码（未做整块碎片校验导致的巧合相同）与错误的按回合区间制定的伪精确门限；
     3. 发现数据方差完全由单图主导后，若固守按回合方差设定的 -0.03 门，属于忽视聚集效应；
     4. 改写后的 H4 直接考核核心科学问题——“自监督学到的残差是否显著胜过不学习的先验规则（$\ge 0.08$ 且下界 $>0$）”，且要求留出事件预测准确率差值 $\le 0.05$。改写目标明确、论证透明，符合预登记规范。
3. **H3 点估计门从 +0.10 改回 +0.05（r1.1 提交 901c6855）的性质判断**：
   - **判断**：**这是科学合理的冻结前登记规模校准（Pre-freeze Registered-scale Calibration），而非事后违规放宽。**
   - **理由**：
     1. **探索数据完全独立于确认段**：无论是批次 3 使用的 30 张图，还是 scale80 探索使用的 80 张图（7_950_000 起），均严格属于探索留出集，与确认段（8_000_000 起）完全不相交。预登记 §5 第 2 条预先声明了“登记规模实测耗时和完整流程结果待回”，根据登记规模的新探索数据修正门限属于正当流程；
     2. **主张的科学有效性未被妥协**：H3 检验的是“学到跨图通用规律是否胜过只记本图事件”。点估计 $\ge +0.05$（即长目标成功率绝对提升 5%）且**下界严格大于 0**，在 400 步复杂的局部可观察网格导航任务中属于坚实的科学效应；
     3. **样本量扩大导致点估计收敛**：小样本（批次 3 仅 17 张长目标图）点估计容易出现向上扰动（+0.240）；当扩展至 47 张长目标图时，点估计稳定在 +0.112。若固守小样本下的高门限（+0.10），在真实效应为 +0.11 时犯假阴性（Type II 错误）的概率极大。将其回调至 r0 的 +0.05 兼顾了统计功效与实在效应；
     4. **透明度完备**：该调整在 r1.1 中清晰列出原因并给出实测区间对比，符合预登记管理规范。

4. **80 张图 × 5 个种子的区间半宽预估（约 0.055）合理性**：
   - 探索批次 3 在 17 张长目标图上的半宽约为 $0.20$；
   - 确认段实测（根据 `oracle_check.json`）5 个种子在 80 张图下长目标覆盖图数合计为 **231 张图**；
   - 根据样本簇渐近理论 $\text{SE} \propto 1/\sqrt{K}$，预测确认段半宽为 $0.20 \times \sqrt{17/231} \approx 0.0543 \approx 0.055$；
   - 对于 H2（点估计 0.24）和 H4 ①（点估计 0.18），下界余量均超过 1.5 倍标准误，统计功效（Statistical Power）充裕，预估合理。
4. **分析自由度控制**：
   - 门限指标死锁在长目标成功率配对差，排除短目标；
   - 种子数、留出图种子偏移（$8\_000\_000 + 1000 \cdot s$）由代码硬约束防重叠；
   - 迷路、SPL、子集等只报告不设门，严密封闭分析自由度。
