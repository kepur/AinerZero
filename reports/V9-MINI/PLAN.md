## 1. 「证明架构正确」能做到什么

实验不能证明一整套架构「正确」，只能逐条支持或推翻具体的主张。能发表的是：几条事先写明的主张，在登记过的考场上过了门；没过的也照实写。

截至 r6 候选稿（数字已由 A26 独立核对），现有证据是这样的：

- 有支持：
  - 门控接管的解析先验加学习残差（S4，二维圆盘）；
  - 外置情景记忆远胜 GRU（S3）；
  - 主动挑样本（S6 一期）。
- 被削弱：
  - 潜空间距离当规划代价（S2 长目标 0/50）；
  - 每一步都加的残差（E1）；
  - 教师合一（S5）。
- 完全空白：没有一个模型同时会预测、记忆和行动。

所以论文的主线应该是「哪些结构让一个笔记本上能训的小模型既会预测又会行动」，而不是「整套架构正确」。

## 2. 流程：探索快跑，确认只登记一次

现在每个阶段都要走「设计 → 复核 → 改稿 → 登记 → 冒烟 → dev → final → 复算」，一个阶段要好几天。快车道分两段：

1. **探索**：
   - 不登记，单次运行以分钟计；
   - 结果只用来调方案，报告里标「探索，不算证据」；
   - 训练图和留出图的种子与已有各阶段的分区都不重叠（`data.py`：训练 7_100_000 起，留出 7_900_000 起）。
2. **确认**：每个里程碑只登记一次。
   - 冻结代码 SHA、门槛和预算；
   - 生成新的留出图，3–5 个种子；
   - 跑一次，由非作者独立复算。

论文表格只用确认段的数字。

## 4. 今天做到哪里（探索）

快速档：60 张训练图，每图 4 条、每条 200 步的游走；训练 3000 步。12 张留出图，每回合先给 400 步探索前缀，目标取前缀里见过、视野唯一的位姿。短目标是 4–10 步，长目标 ≥ 20 步。

| 运行 | 一步误差比 | 5 步误差比 | 代价秩相关（全部 / ≥20 步） |
|---|---|---|---|
| quick-0：预测 + SIGReg | 0.994 | 0.981 | 欧氏 0.33 / 0.02；学到 0.37 / 0.07 |
| quick-1：再加逆动力学项 | **0.019** | 0.055 | 欧氏 0.05 / 0.06；学到 0.29 / 0.05 |

quick-1 的成功率（短 24 个回合，长 24 个回合）：

| 臂 | 短 | 长 |
|---|---|---|
| 随机 | 0.083 | 0 |
| 潜空间欧氏（S2 的做法） | 0.125 | 0 |
| 学到的可达性 | 0.167 | 0 |
| 拓扑图记忆 + 学到的可达性 | 0.167 | 0 |
| 便宜规则（里程计 + 栅格地图 + BFS，不学习） | 1.000 | 1.000 |
| 真值最短路（上界） | 1.000 | 1.000 |

读法（都是单种子、探索性的）：

1. **不加逆动力学项，潜空间坍塌到慢特征**：预测器跟「原地不动」一样准（0.994）。潜空间只记住了房间颜色这类不变量，动作带来的变化没有进去。加上之后降到 0.019，比 S2 的扁平 JEPA 臂（0.036）还低。r5 §1 写了「每层加本层宏动作的逆动力学项」，这是第一次看到它是必需的，而不只是可选。
2. **预测准不等于能规划，再次复现**：欧氏距离与真实距离的秩相关约 0.05，和 S2 的 −0.087 同一个结论。
3. **学到的代价在单帧上不够**：单个 5×5 视野在同一房间里大量重复，从一帧看不出离目标多远。这说明代价必须接在带记忆的信念上（地图或历史），不能只接单帧潜状态。这是 M1 下一步要补的臂。
4. **规律全部已知时，便宜规则 100%**：这个世界里没有解析先验不知道的东西，学习没有用武之地。所以论文要证明学习部分的价值，必须到 M2 那种有未知规律的世界里去比。这也正是架构「已知的写成解析核心，网络只学残差和未知规律」那条决定要检验的地方。

## 6. M1、M2、M3 的设计（2026-11-17 下午，用户「继续 M1 和 M2」）

### 6.1 世界

- **m1**：规律全部已知，即 §4 的世界。
- **m2**：在 m1 上加两条解析先验不知道的规律。
  - **冰带**：每张图两间房里各有一条 2 格宽、贯穿房间的冰带，踩上去会一直滑过整条冰带。
    - 最初试过整间铺冰，会把智能体困在房里（只能停在墙边，对不上门所在的行或列就出不去），所以弃用。
    - 生成时检查位姿图强连通，有陷阱就重放。
  - **单向传送门**：两个，入口与出口至少隔 8 格，相当于捷径。
  - 随机游走里，前进时触发这两条规律的约占 1%，属于稀有事件。
- **规律相关回合**：在真值网格上只按解析先验算出的最短步数，与真实最短步数不同的回合。

### 6.2 臂（同一张表，同样的留出图、前缀和目标）

| 臂 | 记忆 | 前进模型 | 学到的部分 |
|---|---|---|---|
| random | 无 | — | 无 |
| latent_euclid | 单帧 | 世界模型 | 编码器、预测器；代价是潜空间欧氏距离（S2 的做法） |
| latent_learned | 单帧 | 世界模型 | 加拟度量可达性代价 |
| graph_memory | 前缀潜状态构成的拓扑图 | 世界模型 | 同上，图上最短路 |
| gru_belief | GRU 信念 | 世界模型 | 加接在信念上的代价（M1 新增） |
| map_analytic | 度量地图 | 解析先验 | 无（最强的不学习规则） |
| map_memory | 度量地图 + 本图事件记忆 | 解析先验 | 无 |
| **map_hybrid（V9）** | 度量地图 + 本图事件记忆 | 解析先验 + 门控残差（式 16） | 残差与门 |
| map_ungated | 同上 | 不门控的整块分类器 | 分类器 |
| map_ungated_aug | 同上 | 不门控，训练时近处格也随机遮住 | 分类器 |
| oracle | 真值地图 | 真实动力学 | 上界 |

所有地图臂共用同一套定位：

1. 惊讶时先沿朝向的射线就近重定位；
2. 再在整张地图上找唯一一致的位姿；
3. 都找不到就开地图碎片，维护候选位姿集，候选收敛到一个后并回主地图。

这套定位对各臂一样，不偏向哪一臂。

### 6.3 真值依赖清单（r6 新增决定）

| 特权输入 | 哪些臂 | 状态 |
|---|---|---|
| 指南针朝向（绝对朝向） | 全部 | 保留，S2 也给了 |
| 视野几何（视野格到世界偏移）、「墙挡路、前进一格」的解析先验 | 地图臂 | 手写的已知结构，按架构属于几何核心 |
| 格子类型折叠（颜色与规律无关） | 前进模型 | 手写的规范化 |
| 前进模型的训练标签来自真值位姿 | map_hybrid、map_ungated* | **M3 去掉**：改由智能体自己的定位给标签，与真值一致率 0.9994（20 张图、9878 个样本） |
| 测试时的真值位姿 | 无 | 不用 |
| 目标视野唯一 | 任务设计 | 不是智能体输入 |

### 6.4 已经核实的机制（单种子，探索）

1. **加逆动力学项，潜空间才不坍塌**：一步误差比从 0.994 降到 0.019（§4）。
2. **在程序生成的世界里，代价必须接在这张图的显式记忆上**：
   - 远距离秩相关：单帧代价 0.05，GRU 信念 0.13，潜空间欧氏距离约 0.06；
   - 长目标上，这三种做法和拓扑图都是 0，度量地图 100%（m1）。
   - 原因：两个视野隔多远取决于这张图的布局，光看观察定不下来。几百步的历史压进 128 维向量也存不下布局，这和 S3 里 GRU 的长间隔读回很差一致。
3. **不门控的前进模型在分布外失效，门控的会退回先验**：
   - 训练数据里「前方第一格未知」的样本数是 0；
   - 遇到这种射线时，不门控的分类器 70% 判成走不动，把未探索区域当成墙，长目标成功率掉到 0.53；
   - 门控版本 90% 退回解析先验（走一格）。
   - 两者在留出数据上的前进准确率几乎一样（全量训练时事件准确率门控 0.989、不门控 0.979），差别只在分布外。
   - 审稿人一定会问的对照（map_ungated_aug：训练时也遮住近处格）已经加进批次。
4. **样本量曲线上，门控没有省样本的优势**（m2-quick-1）：
   - 300 个样本时，事件准确率不门控 0.79、门控 0.51（门控只见到 3 个事件）；
   - 1000 到 1 万个样本时，不门控持平或略高；
   - 全量 3.3 万时，门控略高（0.989 对 0.979）。

   门控在这里的价值是分布外稳健，不是省样本。

### 7.3 怎么读

1. **规划代价接在显式地图上才行（M1）。**
   - 两个世界里，四种接在潜空间上的做法（欧氏、学到的代价、拓扑图、GRU 信念）长目标都是 0，远距离秩相关都接近 0；
   - 接在度量地图上的做法在 m1 里都是 1。
   - 这支持架构「地图即记忆，同时服务远程规划」那条，以前从未检验。
2. **学到的规律在未知规律的世界里有用（M2）。**
   - 干净的比较是 hybrid 对 analytic、hybrid 对 memory：两边规划都对未知格乐观，差别只在有没有学到的门控残差；
   - 长目标 +0.15、+0.13，区间都不含 0。
   - 只记本图事件、不学习，几乎没有用（+0.03）：
     - 只有亲身经历过的那一处才能用上，没法推广到这张图上没踩过的冰带；
     - 学到的残差能推广。
3. **不门控那一组混着两个因素，不能直接当作「门控有用」的证据。**
   - 训练数据里，被遮住的前方格有 55% 是墙。直接拟合数据的分类器因此倾向于把未知格当成墙：增强后仍有约三分之一判成走不动，规划时就不敢往未探索区域走。
   - 解析先验按设计把未知当可走（乐观）。
   - 这在 m2 里有利（迷路后要探索），在 m1 里反而吃亏：目标都在已知区域内，悲观让路径更短，SPL 0.999 对 0.934。
   - 所以这一组说明的是「在数据说不清的地方，由设计的先验做主」，而且有利有弊，不是单纯的「门控更好」。
4. **还没到上界。** hybrid 长目标 0.79，真值最短路是 1。
   - 每个种子的 16 个失败回合（132 个回合里），全部发生过迷路；成功回合里也有 52/116 迷路过，但找回来了。
   - 失败回合在任务阶段的惊讶次数中位数是 0，而迷路状态下不计惊讶。所以失败多半是带着前缀里的迷路开始任务，在步数预算内没能并回主地图。
   - 改进方向：碎片之间的匹配，不只用当前一帧，而用整块碎片地图去对主地图。

### 7.4 M3：去掉真值标签（探索批次 2）

- **设置：** m2 世界，3 个训练种子，留出图与批次 1 相同，只跑地图类臂，每次约 137 秒。结果在 `reports/V9-MINI/explore/batch2-m3/`。
- **做法：** 前进模型的训练标签不再来自真值位姿，改由只有解析先验的地图智能体在训练图上自己定位得到。真值只用来统计标签对不对。
- **标签质量：** 与真值一致率 0.9988–0.9993（每个种子约 9.5 万个样本，其中事件 1300–1530 个）。
- **前进模型：** 在用真值标注的留出数据上，事件准确率 0.950–0.977。
- **到达目标：**

| 臂 | 长目标成功 | 长目标 SPL | 规律相关成功 | 规律相关 SPL |
|---|---|---|---|---|
| map_hybrid（真值标签） | 0.792 | 0.692 | 0.792 | 0.713 |
| map_hybrid_self（自监督标签） | 0.792 | 0.695 | 0.792 | 0.717 |

- **配对差：** hybrid_self − hybrid，长目标成功率 0 [0, 0]，SPL +0.003 [−0.001, +0.012]。
  hybrid_self − analytic，长目标 +0.153 [+0.069, +0.236]，与 hybrid 相同。
- **重现：** 批次 2 里 map_analytic、map_memory、map_hybrid 的数字与批次 1 完全相同（同一套留出图，代码版本不同）。在这一层上流程是确定性的。

读法：

### 10.2 新组 latent_topo（SPTM / ViNG 式拓扑记忆，`src/ainerzero/v9/mini/topo.py`）

这是文献里这类任务的标准做法：先给一段探索序列，再走到序列里见过的目标画面。全部自监督，只用训练游走的时间间隔和智能体自己的动作，不用真值位姿或距离。

**学到的部分：**
- **可达性网络 R(o_i, o_j)：** 同一条轨迹上相隔不超过 3 步为正例，至少 25 步为负例。
- **运动网络 L(o_t, o_{t+k})：** k ≤ 4，预测 a_t。
- **编码器：** 它有自己的，不共用世界模型。这是在给潜空间一方最好的机会，不是在检验共用编码器。

**记忆图：**
- 节点是前缀的每一帧。
- 沿前缀正向走时，重放当时记下的动作。
- 逆向的时间边，以及学到的捷径边（R ≥ 0.95、观察不同、时间上隔 ≥ 4），交给运动网络。
- 观察完全相同的两帧算同一处，代价接近 0。

**定位：** 先找观察完全相同的帧，取离预期节点最近的；找不到，就在预期节点 4 跳以内按 R 取最像的。

**已知量：** 和地图组一样，知道任务从前缀终点出发，有指南针朝向。

**探索中修掉的三处**（每处都先逐步跟踪查到原因再改）：
1. **原地打转。** 路径的下一跳常常是同一位姿的另一帧，运动网络看到两帧一样的画面，给不出有用的动作。改为沿正向时间边重放动作，同一处不用动。
2. **虫洞。** R 对同一房间里只差一格的两帧也给出 ≥ 0.95。「同一处」边代价为 0，串起来就成了长距离虫洞，例如 (8,15) 一步跳到 (15,14)。改为只有观察完全相同才算同一处；学到的捷径边按 2 步计代价。
3. **定位邻域。** 原来按跳数算邻域，同一处的链也计了跳数，转身后正确的那一帧落在邻域外。改为同一处的边不计跳数（0-1 BFS）。

### 11.1 做法（`src/ainerzero/v9/mini/attn.py`）

这是目标条件的离线 Q 学习：目标用 hindsight 重标记（Kaelbling 1993；HER，Andrychowicz 等 2017），记忆是因果 Transformer，读完整历史（前缀加本回合已走的步）。全部自监督。

**输入：** 只有观察（含指南针朝向）和智能体自己的上一步动作。不读真值位姿，也不读真值距离。

**「到达」的定义：** 当前观察与目标画面完全相同。这和 latent_topo 的「同一处」一样，是对原始观察的比对。

**训练目标（代价按步数计）：**
- 自举：Q(h_t, a_t, g) = 1 + min_a' Q⁻(h_{t+1}, a', g)；下一帧就是目标画面时为 1。Q⁻ 是 Polyak 平均的目标网络。
- 蒙特卡洛上界：同一条游走里，之后第一次看到目标画面用了多少步。
- 目标取 min(自举, 上界, 200)。

**结构：**
- 观察编码加上一步动作的嵌入，进 4 层因果 Transformer（d=128，4 头，RoPE），得到 h_t。
- 目标读出：位置 t 用 [h_t, 目标嵌入] 作查询，对 ≤ t 的所有 [h_j, 第 j 帧的输入嵌入] 做一层多头注意力，再接 MLP 输出 3 个动作的代价。这一层让模型能在记忆里找到目标画面出现在哪里、之后是怎么走的。

**训练数据：**
- 训练图和环境步数都与其他组相同（200 张图，每张 800 步）。
- 只是把每张图的 4 条 200 步游走换成 1 条 800 步游走，训练窗口（600 帧）才覆盖得到测试时 401 帧前缀加回合步数的长度。

**测试：** 每一步把完整历史重新过一遍，选代价最小的动作。随机动作概率 0.05，与其他学到的组相同。

**探索中改的两处：**
1. **初始代价改为偏悲观（约 100 步）。** 自举取 min，值从高处往下收。若从低处起步，每次自举只能往上涨 1，6000 步内到不了长目标需要的量级。这一条是按最初 30 步的日志推算的，没有单独跑对照。
2. **目标网络系数 τ 从 0.01 改为 0.02。** 0.01 时 6000 步的代价均值还在降（27.6）；0.02 时 2500 步左右就稳在 29 上下。

### 11.4 读法

1. **它学到了东西，但不够用。**
   - 第一步选对的比例高于随机猜中，代价与 d* 正相关（§11.2）。
   - 成功率在随机水平附近：短目标 m1 0.133、m2 0.106，长目标 m1 0.033、m2 0。
2. **加步数没用。** 种子 0 的 3000、6000、12000 三个检查点上下跳，60 个回合的标准误约 0.05，看不出趋势。
3. **不是过拟合。** 训练图上同样只有这个水平。瓶颈在学习问题本身：200 张图、16 万环境步，要学会从历史里推出几何。
4. **和 §10 合起来读。**
   - 三类学到的记忆都差得远：循环信念（gru_belief）、拓扑记忆（latent_topo）、注意力（latent_attn）。
   - 拓扑记忆最好，因为它把「沿走过的路重放」写进了结构。
   - 注意力记忆要从数据里自己学出这一点，再加上几何，在这个数据量下学不出来。
5. **不能说的：** 不能说「注意力记忆方法不行」。只试了一种训练方式（离线 Q 学习）和这个数据量，没有做数据量扩展。
