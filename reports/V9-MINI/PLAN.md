## 1. 「证明架构正确」能做到什么

实验不能证明一整套架构「正确」，只能逐条支持或推翻具体的主张。能发表的是：几条事先写明的主张，在登记过的考场上过了门；没过的也照实写。

截至 r6 候选稿（数字已由 A26 独立核对），现有证据是这样的：

- 有支持：
  - 门控接管的解析先验加学习残差（S4，二维圆盘）；
  - 外置情景记忆远胜 GRU（S3）；
  - 主动挑样本（S6 一期）。
- 被削弱：
  - 潜空间距离当规划代价（S2 长目标 0/50）；
  - 每一步都加的残差（E1）；
  - 教师合一（S5）。
- 完全空白：没有一个模型同时会预测、记忆和行动。

所以论文的主线应该是「哪些结构让一个笔记本上能训的小模型既会预测又会行动」，而不是「整套架构正确」。

## 2. 流程：探索快跑，确认只登记一次

现在每个阶段都要走「设计 → 复核 → 改稿 → 登记 → 冒烟 → dev → final → 复算」，一个阶段要好几天。快车道分两段：

1. **探索**：
   - 不登记，单次运行以分钟计；
   - 结果只用来调方案，报告里标「探索，不算证据」；
   - 训练图和留出图的种子与已有各阶段的分区都不重叠（`data.py`：训练 7_100_000 起，留出 7_900_000 起）。
2. **确认**：每个里程碑只登记一次。
   - 冻结代码 SHA、门槛和预算；
   - 生成新的留出图，3–5 个种子；
   - 跑一次，由非作者独立复算。

论文表格只用确认段的数字。

## 4. 今天做到哪里（探索）

快速档：60 张训练图，每图 4 条、每条 200 步的游走；训练 3000 步。12 张留出图，每回合先给 400 步探索前缀，目标取前缀里见过、视野唯一的位姿。短目标是 4–10 步，长目标 ≥ 20 步。

| 运行 | 一步误差比 | 5 步误差比 | 代价秩相关（全部 / ≥20 步） |
|---|---|---|---|
| quick-0：预测 + SIGReg | 0.994 | 0.981 | 欧氏 0.33 / 0.02；学到 0.37 / 0.07 |
| quick-1：再加逆动力学项 | **0.019** | 0.055 | 欧氏 0.05 / 0.06；学到 0.29 / 0.05 |

quick-1 的成功率（短 24 个回合，长 24 个回合）：

| 臂 | 短 | 长 |
|---|---|---|
| 随机 | 0.083 | 0 |
| 潜空间欧氏（S2 的做法） | 0.125 | 0 |
| 学到的可达性 | 0.167 | 0 |
| 拓扑图记忆 + 学到的可达性 | 0.167 | 0 |
| 便宜规则（里程计 + 栅格地图 + BFS，不学习） | 1.000 | 1.000 |
| 真值最短路（上界） | 1.000 | 1.000 |

读法（都是单种子、探索性的）：

1. **不加逆动力学项，潜空间坍塌到慢特征**：预测器跟「原地不动」一样准（0.994）。潜空间只记住了房间颜色这类不变量，动作带来的变化没有进去。加上之后降到 0.019，比 S2 的扁平 JEPA 臂（0.036）还低。r5 §1 写了「每层加本层宏动作的逆动力学项」，这是第一次看到它是必需的，而不只是可选。
2. **预测准不等于能规划，再次复现**：欧氏距离与真实距离的秩相关约 0.05，和 S2 的 −0.087 同一个结论。
3. **学到的代价在单帧上不够**：单个 5×5 视野在同一房间里大量重复，从一帧看不出离目标多远。这说明代价必须接在带记忆的信念上（地图或历史），不能只接单帧潜状态。这是 M1 下一步要补的臂。
4. **规律全部已知时，便宜规则 100%**：这个世界里没有解析先验不知道的东西，学习没有用武之地。所以论文要证明学习部分的价值，必须到 M2 那种有未知规律的世界里去比。这也正是架构「已知的写成解析核心，网络只学残差和未知规律」那条决定要检验的地方。

## 5. 论文和「官方支持」的门槛

能做到的：

- 一台 Mac 一条命令复现每一张表；
- 只依赖 numpy 和 MLX，模型约 36 万参数，快速档 40 秒；

## 6. M1、M2、M3 的设计（2026-11-17 下午，用户「继续 M1 和 M2」）

### 6.1 世界

- **m1**：规律全部已知，即 §4 的世界。
- **m2**：在 m1 上加两条解析先验不知道的规律。
  - **冰带**：每张图两间房里各有一条 2 格宽、贯穿房间的冰带，踩上去会一直滑过整条冰带。
    - 最初试过整间铺冰，会把智能体困在房里（只能停在墙边，对不上门所在的行或列就出不去），所以弃用。
    - 生成时检查位姿图强连通，有陷阱就重放。
  - **单向传送门**：两个，入口与出口至少隔 8 格，相当于捷径。
  - 随机游走里，前进时触发这两条规律的约占 1%，属于稀有事件。
- **规律相关回合**：在真值网格上只按解析先验算出的最短步数，与真实最短步数不同的回合。

### 6.2 臂（同一张表，同样的留出图、前缀和目标）

| 臂 | 记忆 | 前进模型 | 学到的部分 |
|---|---|---|---|
| random | 无 | — | 无 |
| latent_euclid | 单帧 | 世界模型 | 编码器、预测器；代价是潜空间欧氏距离（S2 的做法） |
| latent_learned | 单帧 | 世界模型 | 加拟度量可达性代价 |
| graph_memory | 前缀潜状态构成的拓扑图 | 世界模型 | 同上，图上最短路 |
| gru_belief | GRU 信念 | 世界模型 | 加接在信念上的代价（M1 新增） |
| map_analytic | 度量地图 | 解析先验 | 无（最强的不学习规则） |
| map_memory | 度量地图 + 本图事件记忆 | 解析先验 | 无 |
| **map_hybrid（V9）** | 度量地图 + 本图事件记忆 | 解析先验 + 门控残差（式 16） | 残差与门 |
| map_ungated | 同上 | 不门控的整块分类器 | 分类器 |
| map_ungated_aug | 同上 | 不门控，训练时近处格也随机遮住 | 分类器 |
| oracle | 真值地图 | 真实动力学 | 上界 |

所有地图臂共用同一套定位：

1. 惊讶时先沿朝向的射线就近重定位；
2. 再在整张地图上找唯一一致的位姿；
3. 都找不到就开地图碎片，维护候选位姿集，候选收敛到一个后并回主地图。

这套定位对各臂一样，不偏向哪一臂。

### 6.3 真值依赖清单（r6 新增决定）

| 特权输入 | 哪些臂 | 状态 |
|---|---|---|
| 指南针朝向（绝对朝向） | 全部 | 保留，S2 也给了 |
| 视野几何（视野格到世界偏移）、「墙挡路、前进一格」的解析先验 | 地图臂 | 手写的已知结构，按架构属于几何核心 |
| 格子类型折叠（颜色与规律无关） | 前进模型 | 手写的规范化 |
| 前进模型的训练标签来自真值位姿 | map_hybrid、map_ungated* | **M3 去掉**：改由智能体自己的定位给标签，与真值一致率 0.9994（20 张图、9878 个样本） |
| 测试时的真值位姿 | 无 | 不用 |
| 目标视野唯一 | 任务设计 | 不是智能体输入 |

### 6.4 已经核实的机制（单种子，探索）

1. **加逆动力学项，潜空间才不坍塌**：一步误差比从 0.994 降到 0.019（§4）。
2. **在程序生成的世界里，代价必须接在这张图的显式记忆上**：
   - 远距离秩相关：单帧代价 0.05，GRU 信念 0.13，潜空间欧氏距离约 0.06；
   - 长目标上，这三种做法和拓扑图都是 0，度量地图 100%（m1）。
   - 原因：两个视野隔多远取决于这张图的布局，光看观察定不下来。几百步的历史压进 128 维向量也存不下布局，这和 S3 里 GRU 的长间隔读回很差一致。
3. **不门控的前进模型在分布外失效，门控的会退回先验**：
   - 训练数据里「前方第一格未知」的样本数是 0；
   - 遇到这种射线时，不门控的分类器 70% 判成走不动，把未探索区域当成墙，长目标成功率掉到 0.53；
   - 门控版本 90% 退回解析先验（走一格）。
   - 两者在留出数据上的前进准确率几乎一样（全量训练时事件准确率门控 0.989、不门控 0.979），差别只在分布外。
   - 审稿人一定会问的对照（map_ungated_aug：训练时也遮住近处格）已经加进批次。
4. **样本量曲线上，门控没有省样本的优势**（m2-quick-1）：
   - 300 个样本时，事件准确率不门控 0.79、门控 0.51（门控只见到 3 个事件）；
   - 1000 到 1 万个样本时，不门控持平或略高；
   - 全量 3.3 万时，门控略高（0.989 对 0.979）。

   门控在这里的价值是分布外稳健，不是省样本。
