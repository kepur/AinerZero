1: """S1 dataset identity, feature/target view and strict partition guards.
2: 
3: Layout (level-1 notice #297): the dataset bytes live under
4: ``artifacts/v9/s1/datasets/<dataset_digest>/`` and the run root
5: ``artifacts/v9/s1/phase1/`` only carries a ``dataset_ref.json`` pointing at it.
6: ``reports/`` keeps manifests and their SHA256 only.
7: 
8: Inside a dataset directory:
9: 
10: - ``packets/{train,development}.jsonl`` -- one payload-only row per observation
11:   (episode_id + partition + seq + payload).  This is the only file the training
12:   path may read; it never contains truth fields.
13: - ``truth/{train,development}.jsonl`` -- evaluator-only truth (agent pose,
14:   entities, handle map, world occupancy).  Only ``load_truth_view`` reads it.
15: - ``dataset_manifest.json`` -- plan, counts, per-episode digests, generator
16:   source identity (SHA-256 map; the arena code is uncommitted), byte sizes and
17:   the dataset digest.
18: 
19: The ``final`` partition has no directory, no loader and no code path that could
20: create it: every public function asserts the partition is train/development.
21: """
