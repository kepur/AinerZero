## 1. 任务背景与核心目标

按统筹规约（`AinerRelay/reports/coordination/codex-20261026/BLOCKERS-NEXT-BATCH.md` §4）与原 T4 用户授权（`RESEARCH_LOG.md:620-646` `R20261016-T4`），实现真实运行前的受控 CLI 工程路径：
1. **统一 CLI 入口**: `ainerzero teacher-benchmark` 子命令，支持 `--mode inspect` 与 `--mode run`。
2. **零副作用检查 (inspect)**: 纯只读！绝不创建或获取锁文件、绝不创建或修改 SQLite 账本、绝不导入 MLX/CoreML、绝不加载模型权重。
3. **一级批准门禁 (Approval Gate)**: 强绑定 `RESEARCH_LOG.md` 的 `R20261016-T4` 批准节与 `批准 T4` 关键字，缺失或篡改一律拒绝并退出码 `3` (`EXIT_REFUSED_APPROVAL`)。
4. **保守预算核算与预扣 (Budget Gate & RunStore Pre-reservation)**:
   - 单次运行墙钟预算上限 ≤ 600.0s (`existing_T4_per_run_seconds`)；
   - 累计运行墙钟预算上限 ≤ 1800.0s (`existing_T4_budget_seconds`)；
   - 预扣预算：在调用模型适配器前，调用 `RunStore.consume(run_id, active_seconds=...)` 执行原子预扣，崩溃不退费；超限一律拒绝并退出码 `5` (`EXIT_REFUSED_BUDGET`)。
5. **资源门控 (Resource Gate)**:
   - 进程 RSS ≤ 32.0 GiB；
   - 同一时刻最多常驻单模型；
   - 超限一律拒绝并退出码 `2` (`EXIT_REFUSED_RESOURCE`)。
6. **跨进程互斥锁 (Shared Worker Lock Gate)**:
   - 复用 CLI `worker_lock`（非阻塞 exclusive flock）；
   - 发生争锁立即退出并返回码 `4` (`EXIT_LOCK_BUSY`)。
7. **模型精确身份绑定**: 绑定 T21/T22 封存的 12 个官方权重文件及其精确 SHA256 与字节大小（总计 1,655,306,028 字节）。
8. **绝对安全与代码卫生**:
   - 严禁生产代码包含任何假后端或环境变量绕过开关（无 `--fake-backend`、无 `AWZ_D14_SABOTAGE` 类后门）；
   - 纯 CPU 工程测试，真实模型运行数 `real_model_runs = 0`，不重复下载安装外部依赖；
   - 坏控验证完全在隔离的临时目录进行单处真实源码突变。

## 3. 退出码规约

| 退出码 | 标识符 | 触发条件 |
| :--- | :--- | :--- |
| **0** | `EXIT_COMPLETED` | inspect 检查通过或受控 benchmark 成功运行 |
| **1** | `EXIT_FAILED` | 执行过程抛出未受保护的未知异常或适配器内部错误 |
| **2** | `EXIT_REFUSED_RESOURCE` | 进程 RSS > 32 GiB 或系统资源门超限 |
| **3** | `EXIT_REFUSED_APPROVAL` | `RESEARCH_LOG.md` 缺少 `R20261016-T4` 或 `批准 T4` 关键字 |
| **4** | `EXIT_LOCK_BUSY` | 共享互斥锁 `m0-worker.lock` 被其他工作进程持有 |
| **5** | `EXIT_REFUSED_BUDGET` | 单次运行请求 > 600s 或 RunStore 累计预算 > 1800s |
