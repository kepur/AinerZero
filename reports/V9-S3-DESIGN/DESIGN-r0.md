## 1. 问题与假设

只问一件事：**答案只存在于同一回合更早的经历里时，用什么记忆最好？**

- **H1（结构）：** 外置非参数情景库配手工线索，长间隔读回准确率高于循环隐状态（M2 一路的结构）。
- **H2（检索）：** 线索互相混淆时，FAR 式学习检索高于手工线索。
- **H3（保护，式 6）：** 换一批世界继续训练后，旧世界族的读回不退化超过 ε。

**第一阶段不回答：** 跨回合记忆、巩固、FAST→MID→SLOW 晋升、Titans、Nested Learning，留给第二阶段。阳性也只说明这个任务上的结论，不宣称通用记忆能力。

## 2. 世界与任务：GridLab-S3

新包 `src/ainerzero/v9/experiments/s3/`。只读复用 S2 的 `make_layout`、`step`、`compute_ego_view`，不改 S2 的任何文件。

**观察（允许观察，不含绝对坐标）：**
- 视野半径 1（3×3）的地形和内容 token 通道，不用 S2 的 7×7。原因见下表；
- 朝向 one-hot、上一动作、是否撞墙（1 bit）。`dt` 固定为 1，S3 不测多时间尺度。

**里程计与打滑：** 前进以概率 `p_slip = 0.05` 静默失败（不撞墙、不告知）。学生只能按「下了前进且没撞墙」累计位姿，所以位姿线索会漂移。正式成绩用估计位姿，真值位姿只作诊断上界。

**内容层：** 每回合 `M = 8` 个内容格，token 取 `C = 8` 类。每个内容格在回合内有登记的换 token 时刻，返回事件中约一半已经换过。

**行为策略（巡游）：** 用反向多源 BFS 走向目标，10% 噪声。优先走到期的返回，否则去新目标，返回间隔按分桶抽取。

**读回事件：** 回到内容格时提问「上次到这里时，这里是什么 token？」，C 类分类。主指标只看 **token 已换过** 的事件，这时当前观察帮不上忙，照抄当前观察必错。

**一级实测**（`tier1-probe/`，16 个世界，T = 360，M = 8）：

| 指标 | S2 现有生成器 | 巡游原型 |
|---|---|---|
| 一回合走过的不同格子（中位） | 15.5 | 100.5 |
| 最常停留格占比（中位） | 33% | 3.6% |
| 每回合返回事件（中位） | — | 7.5–8.5 |

长间隔（≥ 80 步）返回时，手工线索取到正确地点的比例：

| 视野半径 | 打滑率 | 位姿 | 视野 | 两者结合（λ = 0.5） |
|---|---|---|---|---|
| 3 | 0.05 | 0.37 | 1.00 | 1.00 |
| 2 | 0.05 | 0.37 | 0.77 | 0.88 |
| **1** | **0.05** | **0.37** | **0.17** | **0.63** |
| 1 | 0 | 1.00 | 0.23 | 1.00 |

半径 3 时视野一匹配就 100%，手工线索没有提升空间，H2 无从检验。选半径 1、打滑 0.05：两条线索单独都不够，结合起来也远低于上限。这些数字是用原型测的，§5 的探针要在正式生成器上复测。

## 3. 臂

各臂共用同一个小编码器和读出头结构，参数量相差不超过 10%，同样的数据和更新次数。

| 臂 | 记忆 | 作用 |
|---|---|---|
| A0 | 无（零状态） | 地板，验证任务确实需要历史 |
| A1 | GRU 隐状态 | 循环结构基线 |
| A2 | 情景库 + 手工线索（位姿、视野、时间，权重在 train 上拟合后冻结） | H1 |
| A3 | 情景库 + FAR 式学习检索 | H2 |
| O | 情景库 + 真值检索 | 上界，只作诊断 |
| N | A2，但库内容按回合内打乱 | 负对照，应掉到地板 |

- **情景库：** 每步写一条记录（估计位姿、时间、视野嵌入、观察到的 token）。写入不改网络参数。
- **FAR 式检索：** 对每个查询，在手工线索取的前 K 条（K = 8）里，用「带这条记录与不带时读回损失的差」作效用，训练打分头。编码器的梯度截断，防止检索和表示互相追逐。

## 4. 指标与门

**主指标：** 长间隔（≥ 80 步）、token 已换过的事件的读回准确率。按回合配对 bootstrap 取 95% 区间。

下列门槛是**拟定值**，冻结前由 §5 探针校准，不按 dev 调整：

| 门 | 判据（拟定） |
|---|---|
| H1 | A2 − A1 ≥ 0.10，且配对 95% 区间下界 > 0 |
| H2 | A3 − A2 ≥ 0.05，且配对 95% 区间下界 > 0 |
| H3（式 6） | 换世界族后旧族读回下降 ≤ 0.05 |
| 合法性：地板 | A0 ≤ 1/C + 0.05 |
| 合法性：上界 | O ≥ 0.90 |
| 合法性：负对照 | N ≤ 1/C + 0.05 |

合法性门任何一条不过，整个实验判无效，不解读 H1–H3。

**常设报告，不进门：** M2 干扰诊断（`metrics.py` 的 `memory_interference`）、按间隔分桶的曲线、token 未换过的事件、检索的 precision@1、训练步耗时、峰值内存。

## 5. 冻结前探针（全过才登记预算）

| 探针 | 内容 | 过线 |
|---|---|---|
| P-a 数据 | 正式生成器、100 个世界 | 不同格子中位 ≥ 60；最常停留格占比最大 ≤ 0.15；≥ 90% 回合有长间隔已换 token 事件；已换比例 0.4–0.6 |
| P-b 寻路 | 反向 BFS | 无噪声到达率 100% |
| P-c 线索 | 手工线索 precision@1（长间隔） | 结合后在 0.40–0.85 之间 |
| P-d 上界 | O 短训 ≤ 500 步 | ≥ 0.90，否则任务或读出头有问题 |
| P-e 地板 | A0 短训 | ≤ 1/C + 0.05，否则有捷径 |
| P-f 负对照 | N 短训 | ≤ 1/C + 0.05 |
| P-g 成本 | 各臂实测步耗时 | 用于最终预算 |

P-d、P-e、P-f、P-g 需要短训练，总计上限 20 分钟，MLX CPU，一级登记。缺任何一项实测数据都判未通过。

## 6. 分区与用量

- train、dev、final 用互不重叠的登记种子命名空间（`s3p1-*`），世界布局和内容都不重叠。
- dev 至多使用两次，每次写明用途。
- final 在预登记冻结后才生成，只读一次，要有唯一批准行。

## 9. 未决与风险

- **3×3 视野可能太难：** 编码器也许学不到有用的视野嵌入。P-d 过线前不继续。
- **任务可能太像「查表」：** H1 阳性可能只说明外置存储比循环状态更适合精确读回，这本身符合预期。报告里要如实写明这一点，不外推到规划或长期记忆。
- **撞墙 bit 算不算允许观察：** 拟定算自身本体感觉，待审。
- **H3 的世界族怎么划分：** 拟定按 token 语义映射与布局种子两轴切分，待审。
- **S2 缺陷的波及面：** `_find_path_step` 只在 `s2/data.py` 使用。S1、E1 走 AWZ 的场地生成器，不经过它。
