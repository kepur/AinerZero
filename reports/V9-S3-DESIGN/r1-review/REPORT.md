## 2. 一级没有采纳的意见与无记忆策略准确率穷举

### 2.1 一级否决 P201 建议的合理性
P201 报告曾建议「主指标测试集 1:1 混合已换与未换事件」，宣称这样可以使无记忆先验策略严格锁定在 $1/C$。
一级在 r1 中明确指出了该建议的漏洞：
- 若在 1:1 混合集上评估单一准确率，一个最简单的无记忆模型只要采取「照抄当前 token」策略，在 50% 的未换事件上准确率为 100%，综合准确率立刻达到：
  $$\text{Acc}_{\text{mixed}} = 0.5 \times 1.0 + 0.5 \times 0.0 = 50.0\% \gg \frac{1}{C} = 12.5\%$$
- 50% 的基线将严重污染主指标，使得主指标失去分辨力。

一级的替代方案是：**主指标只看已换过事件，地板设为 $1/(C-1) + 0.03 = 17.3\%$，另设未换事件有效性门（$\ge 80\%$）**。

### 2.2 无记忆策略准确率穷举计算
设类别数 $C = 8$，内容格初始 token 为 $c_{old}$，当前观察到 token 为 $c_{current}$。
在已换事件中，$c_{current} = c_{new} \ne c_{old}$，且 $c_{old}$ 均匀分布于剩余 $C-1 = 7$ 个类别中。
在未换事件中，$c_{current} = c_{old}$。

| 无记忆策略 | 预测动作 $\hat{c}$ | 已换事件准确率（主指标） | 未换事件准确率（有效性门） | 穿透判定与结论 |
|---|---|:---:|:---:|---|
| **1. 照抄当前**<br>(Copy Current) | $\hat{c} = c_{current}$ | **0.0%**<br>($c_{new} \ne c_{old}$) | **100.0%**<br>($c_{current} = c_{old}$) | **无法过线**。主指标得 0 分，远低于有效记忆模型，无法通过 H1/H2。 |
| **2. 排除当前**<br>(Exclude Current) | 均匀抽取于<br>$\{1,\dots, C\} \setminus \{c_{current}\}$ | **14.29%**<br>($1/(C-1) = 1/7$) | **0.0%**<br>($\hat{c} \ne c_{current} = c_{old}$) | **无法过线**。主指标 $14.3\% \le 17.3\%$ 无法突破地板门；且未换事件 $0\% \ll 80\%$ 直接触发合法性门熔断！ |
| **3. 类频率/静态先验**<br>(Uniform Guess) | 均匀猜某一固定类<br>或采样自全局边缘分布 | **12.50%**<br>($1/C = 1/8$) | **12.50%**<br>($1/C = 1/8$) | **无法过线**。未换事件 $12.5\% \ll 80\%$ 挂在有效性门；主指标同样在地板以下。 |
| **4. 时间步插值策略**<br>(Time-conditional mixture) | 概率 $\alpha$ 照抄，<br>概率 $1-\alpha$ 排除 | **$(1-\alpha) \times 14.29\%$** | **$\alpha \times 100.0\%$** | **无法过线**。若要满足未换事件 $\ge 80\%$，必须 $\alpha \ge 0.8$；而此时已换事件准确率至多 $(1-0.8) \times 14.29\% = 2.86\%$，主指标彻底垫底！ |

**结论：** 一级的处理机制构成了严密的双向夹逼：企图在已换事件上利用排除捷径的模型，其未换事件准确率必然逼近 0%，被有效性门一票否决；企图兼顾未换事件的模型，其已换事件准确率被压制在 $< 3\%$。**该机制在数学上严格成立，彻底堵死了所有无记忆策略。**

## 3. 新捷径排查

1. **「新 token 必须不同于旧 token」**：
   - 彻底消除了「已换」事件中由于随机碰撞产生 $c_{new} == c_{old}$ 的语义混淆。
   - 使得已换事件的条件概率空间严格约束在 $C-1$ 个候选中，与地板门 $1/(C-1) + 0.03$ 完全对齐。
   - 未引入任何未被对冲的信息泄露。
2. **「多路候选池」**：
   - 候选池由位姿前 4（带打滑估计）、视野前 4（中心 3x3 混淆视野）、两者结合前 4 合并去重构成（$K \le 12$）。
   - 候选池检索全程只使用当前估计状态与历史感知记录，**严禁且无法访问历史真实 token 或绝对真实位姿**。
   - 在打滑与视野混淆下，真实记录并不保证必然在候选池中（由探针 P-c2 检验召回率 $\ge 0.80$），不存在恒真保送。
   - A3 打分头训练时对编码器梯度截断（detach），杜绝了打分头与特征编码器的协同泄漏。
3. **「回合结束清空」**：
   - 严格限定为回合内记忆（Within-episode memory），杜绝跨回合历史残留导致的虚假线索泄漏。
   - 在 H3 迁移评测中，回合清空排除了旧世界族物理条目残留的干扰，使得 H3 纯净测出神经网络参数（编码器、读出头、打分头）的持续学习抗遗忘特性。
- **排查结论：无新增泄漏，无恒真情况。**

### 7.4 `memory_interference`
**源码出处：** `src/ainerzero/v9/experiments/s1/metrics.py:336-348`
```python
def memory_interference(
    *,
    before: Mapping[str, float],
    after: Mapping[str, float],
    history_paired: Mapping[str, float] | None = None,
    zero_state: Mapping[str, float] | None = None,
) -> dict:
    """Retention delta after writing new memories (no parameter updates)."""
    keys = sorted(set(before) & set(after))
    if not keys:
        raise ValueError("before and after metrics share no keys")
    deltas = {key: float(after[key]) - float(before[key]) for key in keys}
    result = {
        "retention_delta": deltas,
        "worst_retention_delta": max(deltas.values()),
        "keys": keys,
    }
```
